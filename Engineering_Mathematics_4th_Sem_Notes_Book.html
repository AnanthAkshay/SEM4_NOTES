Unit 1 Notes

Statistics & Discrete Probability Distributions

Covers curve fitting of straight lines, parabolas, and geometric curves, correlation/regression, and rigorous mathematical analysis of Binomial and Poisson distributions including mean and variance proofs.

unit_1_ppt_notes.pdf
Open in New Tab

Syllabus Outline

Least-Squares Curve Fitting
Fitting linear $y=a+bx$, quadratic parabolic $y=a+bx+cx^2$, and power/geometric curves to experimental data.
Correlation & Regression
Pearson's correlation coefficient, lines of regression, and multiple linear regression planes.
Discrete Probability
PMF, Mathematical Expectation, Variance. Discrete distributions: Binomial & Poisson (rigorous mean/variance derivations, Poisson approximation).

Key Math Formulas

Linear Fit ($y = a + bx$)
$$\sum y = na + b\sum x$$ $$\sum xy = a\sum x + b\sum x^2$$
Parabolic Fit ($y = a + bx + cx^2$)
$$\sum y = na + b\sum x + c\sum x^2$$ $$\sum xy = a\sum x + b\sum x^2 + c\sum x^3$$ $$\sum x^2y = a\sum x^2 + b\sum x^3 + c\sum x^4$$
Exponential Fits ($y = ae^{bx}$ & $y = ab^x$)
$$\text{For } y = ae^{bx}: \ln y = \ln a + bx \implies Y = A + bX$$ $$\sum Y = nA + b\sum X, \quad \sum XY = A\sum X + b\sum X^2 \quad (a = e^A)$$ $$\text{For } y = ab^x: \log y = \log a + x\log b \implies Y = A + BX$$ $$\sum Y = nA + B\sum X, \quad \sum XY = A\sum X + B\sum X^2 \quad (a = 10^A, \, b = 10^B)$$
Power / Geometric Curve ($y = ax^b$)
$$\log y = \log a + b\log x \implies Y = A + bX$$ $$\sum Y = nA + b\sum X, \quad \sum XY = A\sum X + b\sum X^2 \quad (a = 10^A)$$
Pearson Correlation Coefficient ($r$)
$$r = \frac{n\sum xy - \sum x\sum y}{\sqrt{[n\sum x^2 - (\sum x)^2][n\sum y^2 - (\sum y)^2]}}$$ $$r = \frac{\text{Cov}(X,Y)}{\sigma_X \sigma_Y}$$
Regression Coefficients ($b_{yx}$, $b_{xy}$)
$$b_{yx} = r\frac{\sigma_Y}{\sigma_X} = \frac{n\sum xy - \sum x\sum y}{n\sum x^2 - (\sum x)^2}$$ $$b_{xy} = r\frac{\sigma_X}{\sigma_Y} = \frac{n\sum xy - \sum x\sum y}{n\sum y^2 - (\sum y)^2}$$
Regression Lines & Relationships
$$\text{Line of } y \text{ on } x: y - \bar{y} = b_{yx}(x - \bar{x})$$ $$\text{Line of } x \text{ on } y: x - \bar{x} = b_{xy}(y - \bar{y})$$ $$r = \pm\sqrt{b_{yx} \cdot b_{xy}} \quad (\text{sign matches regression coeffs})$$ $$\tan\theta = \frac{1-r^2}{|r|}\left(\frac{\sigma_x\sigma_y}{\sigma_x^2+\sigma_y^2}\right)$$
Multiple Linear Regression Plane
$$Y = a + bX_1 + cX_2$$ $$\sum Y = na + b\sum X_1 + c\sum X_2$$ $$\sum X_1Y = a\sum X_1 + b\sum X_1^2 + c\sum X_1X_2$$ $$\sum X_2Y = a\sum X_2 + b\sum X_1X_2 + c\sum X_2^2$$
Discrete Random Variables
$$\text{Mean } \mu = E(X) = \sum x_i P(x_i)$$ $$\text{Var } \sigma^2 = E(X^2) - [E(X)]^2 = \sum x_i^2 P(x_i) - \mu^2$$ $$E(aX+b) = aE(X)+b, \quad \text{Var}(aX+b) = a^2\text{Var}(X)$$
Binomial Distribution
$$P(X=x) = \binom{n}{x}p^x q^{n-x} \quad (q = 1-p)$$ $$\text{Mean } \mu = np, \quad \text{Variance } \sigma^2 = npq$$ $$\text{Recurrence: } P(x+1) = \frac{n-x}{x+1}\cdot\frac{p}{q}\cdot P(x)$$
Poisson Distribution
$$P(X=x) = \frac{e^{-\lambda}\lambda^x}{x!}$$ $$\text{Mean } \mu = \lambda, \quad \text{Variance } \sigma^2 = \lambda$$ $$\text{Recurrence: } P(x+1) = \frac{\lambda}{x+1}P(x)$$ $$\text{Approximation: } \lambda = np \quad (\text{when } n \ge 100, \, p \le 0.01)$$
Unit 2 Notes

Continuous Probability & Joint Distributions

Focuses on Continuous distributions (Uniform, Exponential, Gamma, Normal) and Joint/Bivariate probability distributions (Discrete & Continuous marginals, conditional distribution, covariance, and correlation coefficient).

Probability Distribution.pdf
Open in New Tab

Syllabus Outline

Continuous Distributions
Uniform (Rectangular) and Exponential distributions with mean and variance proofs. Gamma and Normal distributions (properties, standard normal computations).
Joint probability distributions
Discrete and continuous bivariate joints, marginal distributions, conditional probability distributions, expectation, covariance, correlation coefficient, and independence checks.

Key Math Formulas

Continuous Random Variables
$$\int_{-\infty}^{\infty} f(x) dx = 1, \quad P(a \le X \le b) = \int_a^b f(x) dx$$ $$\text{CDF: } F(x) = P(X \le x) = \int_{-\infty}^{x} f(t) dt \implies f(x) = \frac{d}{dx}F(x)$$ $$\text{Mean } \mu = E(X) = \int_{-\infty}^{\infty} x f(x) dx$$ $$\text{Variance } \sigma^2 = E(X^2) - \mu^2 = \int_{-\infty}^{\infty} x^2 f(x) dx - \mu^2$$ $$\text{Median } M: \int_{-\infty}^{M} f(x) dx = 0.5$$
Uniform (Rectangular) Distribution
$$f(x) = \frac{1}{b-a} \quad (a \le x \le b), \quad F(x) = \frac{x-a}{b-a}$$ $$\text{Mean } \mu = \frac{a+b}{2}, \quad \text{Variance } \sigma^2 = \frac{(b-a)^2}{12}, \quad \sigma = \frac{b-a}{2\sqrt{3}}$$
Exponential Distribution
$$f(x) = \lambda e^{-\lambda x} \quad (x \ge 0), \quad F(x) = 1 - e^{-\lambda x}$$ $$\text{Mean } \mu = \frac{1}{\lambda}, \quad \text{Variance } \sigma^2 = \frac{1}{\lambda^2}, \quad \sigma = \frac{1}{\lambda}$$
Gamma Distribution
$$f(x) = \frac{\beta^\alpha x^{\alpha-1} e^{-\beta x}}{\Gamma(\alpha)} \quad (x \ge 0, \, \alpha, \beta > 0)$$ $$\Gamma(\alpha) = \int_0^{\infty} t^{\alpha-1} e^{-t} dt \implies \Gamma(n) = (n-1)!$$ $$\text{Mean } \mu = \frac{\alpha}{\beta}, \quad \text{Variance } \sigma^2 = \frac{\alpha}{\beta^2}$$
Normal & Standard Normal
$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2} \implies Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$$ $$\text{Symmetry: } P(Z \le -z) = 1 - \Phi(z), \quad P(|Z| \le 1.96) = 0.95$$
Bivariate Discrete Joints
$$\sum_i \sum_j p_{ij} = 1, \quad P_X(x_i) = \sum_j p_{ij}, \quad P_Y(y_j) = \sum_i p_{ij}$$ $$\text{Cond: } P(X=x_i | Y=y_j) = \frac{p_{ij}}{P_Y(y_j)}$$ $$\text{Cov}(X,Y) = E(XY) - E(X)E(Y) \quad (E(XY) = \sum\sum x_i y_j p_{ij})$$ $$\text{Corr: } \rho = \frac{\text{Cov}(X,Y)}{\sigma_X \sigma_Y}, \quad \text{Indep Check: } p_{ij} = P_X(x_i) \cdot P_Y(y_j)$$
Bivariate Continuous Joints
$$\int\int f(x,y) dx dy = 1, \quad f_X(x) = \int f(x,y) dy, \quad f_Y(y) = \int f(x,y) dx$$ $$\text{Cond: } f_{X|Y}(x|y) = \frac{f(x,y)}{f_Y(y)}, \quad E(XY) = \int\int xy f(x,y) dx dy$$ $$\text{Indep Check: } f(x,y) = f_X(x) \cdot f_Y(y)$$
Unit 3 Notes

Markov Chains & Queuing Theory

Introduces stochastic processes, transition probability matrices (TPMs), stationary distributions, absorbing chains, and queuing models (M/M/1, M/M/s, M/D/1) with infinite/finite capacity equations.

Updated Unit - III - IS$1.pdf
Open in New Tab

Syllabus Outline

Markov Chains
Stochastic processes, probability vectors, regular transition probability matrices, stationary distributions, absorbing states, and absorbing Markov chains.
Queuing Systems
Kendall's notation, queue structures. Single server infinite $(M/M/1):(\infty/\text{FIFO})$ and finite $(M/M/1):(N/\text{FIFO})$ capacity models. Multi-server $(M/M/s):(\infty/\text{FIFO})$ and deterministic service $(M/D/1):(\infty/\text{FIFO})$ models.

Key Math Formulas

Markov Vector & TPM
$$\text{Vector: } v_i \ge 0, \sum v_i = 1 \quad \text{TPM: } p_{ij} \ge 0, \sum_j p_{ij} = 1$$ $$\text{n-step state: } v^{(n)} = v^{(0)} P^n, \quad P^{(n)} = P^n$$ $$\text{Regularity: } \exists k > 0 \text{ s.t. } P^k_{ij} > 0$$ $$\text{Stationary Dist: } \pi P = \pi \quad (\sum \pi_i = 1)$$
Absorbing Markov Chains
$$\text{Absorbing state: } p_{ii} = 1 \quad \text{Canonical: } P = \begin{pmatrix} I & O \\ R & Q \end{pmatrix}$$ $$\text{Fundamental Matrix: } N = (I - Q)^{-1}$$ $$\text{Steps to Absorption: } T = N \mathbf{1} \quad (\mathbf{1} = \text{column vector of ones})$$ $$\text{Absorption Probabilities: } B = N R$$
Little's Laws & Queue Traffic
$$\text{Traffic } \rho = \frac{\lambda}{\mu} \quad (s=1), \quad \rho = \frac{\lambda}{s\mu} \quad (s > 1)$$ $$L_s = \lambda_e W_s, \quad L_q = \lambda_e W_q$$ $$W_s = W_q + \frac{1}{\mu}, \quad L_s = L_q + \frac{\lambda_e}{\mu} \quad (\lambda_e = \text{effective rate})$$
Model I: $(M/M/1) : (\infty/\text{FIFO})$
$$P_0 = 1 - \rho, \quad P_n = (1-\rho)\rho^n, \quad P(\ge n) = \rho^n$$ $$L_s = \frac{\lambda}{\mu-\lambda}, \quad L_q = \frac{\lambda^2}{\mu(\mu-\lambda)}$$ $$W_s = \frac{1}{\mu-\lambda}, \quad W_q = \frac{\lambda}{\mu(\mu-\lambda)}$$ $$\text{Non-empty queue length: } L'_q = \frac{\mu}{\mu-\lambda}$$
Model II: $(M/M/1) : (N/\text{FIFO})$
$$P_0 = \frac{1-\rho}{1-\rho^{N+1}} \quad (\rho \ne 1), \quad P_n = \rho^n P_0 \quad (n \le N)$$ $$L_s = \frac{\rho}{1-\rho} - \frac{(N+1)\rho^{N+1}}{1-\rho^{N+1}} \quad (\text{if } \rho=1, \, L_s = \frac{N}{2})$$ $$\lambda_e = \lambda(1 - P_N), \quad L_q = L_s - (1 - P_0)$$ $$W_s = \frac{L_s}{\lambda_e}, \quad W_q = \frac{L_q}{\lambda_e}$$
Model III: $(M/M/s) : (\infty/\text{FIFO})$
$$P_0 = \left[ \sum_{n=0}^{s-1} \frac{1}{n!}\left(\frac{\lambda}{\mu}\right)^n + \frac{1}{s!}\left(\frac{\lambda}{\mu}\right)^s \left(\frac{1}{1-\rho}\right) \right]^{-1}$$ $$P_n = \frac{1}{n!}\left(\frac{\lambda}{\mu}\right)^n P_0 \quad (n < s), \quad P_n = \frac{1}{s! s^{n-s}}\left(\frac{\lambda}{\mu}\right)^n P_0 \quad (n \ge s)$$ $$L_q = \frac{P_0 (\lambda/\mu)^s \rho}{s!(1-\rho)^2}, \quad L_s = L_q + \frac{\lambda}{\mu}$$ $$W_q = \frac{L_q}{\lambda}, \quad W_s = W_q + \frac{1}{\mu}, \quad P(W > 0) = \frac{(\lambda/\mu)^s P_0}{s!(1-\rho)}$$
Model IV: $(M/D/1) : (\infty/\text{FIFO})$
$$L_q = \frac{\rho^2}{2(1-\rho)}, \quad L_s = L_q + \rho$$ $$W_q = \frac{L_q}{\lambda}, \quad W_s = W_q + \frac{1}{\mu}$$
Unit 4 Notes

Sampling Theory & Statistical Inference

Covers Central Limit Theorem, standard error, type-I and type-II errors, level of significance (LOS), large sample Z-tests, and small sample t-tests, F-tests, and Chi-Square ($\chi^2$) goodness of fit tests.

Unit - IV - IS41.pdf
Open in New Tab

Syllabus Outline

Sampling distributions
Sampling means, Central Limit Theorem, Standard Errors. Hypothesis basics: Null ($H_0$), Alternative ($H_1$), Type I/II errors, Level of Significance.
Large & Small Sample Tests
Large sample single mean Z-tests. Small sample Student's t-test (single mean, difference of means), F-test (variance ratio tests).
Chi-Square Test
Chi-Square ($\chi^2$) distribution test for goodness-of-fit and independence of attributes in contingency tables.

Key Math Formulas

Standard Errors (S.E.)
$$\text{Mean: } \text{S.E.}(\bar{x}) = \frac{\sigma}{\sqrt{n}} \quad (\text{finite pop: } \frac{\sigma}{\sqrt{n}}\sqrt{\frac{N-n}{N-1}})$$ $$\text{Diff Means: } \text{S.E.}(\bar{x}_1-\bar{x}_2) = \sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}$$ $$\text{Proportion: } \text{S.E.}(p) = \sqrt{\frac{PQ}{n}} \quad (\text{Diff Prop: } \sqrt{\frac{P_1Q_1}{n_1} + \frac{P_2Q_2}{n_2}})$$
Hypothesis & Critical Values
$$\text{Type I Error: Reject } H_0 \text{ when true (Prob } \alpha)$$ $$\text{Type II Error: Accept } H_0 \text{ when false (Prob } \beta)$$ $$\text{Critical } Z \text{ at } 5\%: \text{Two-tail } \pm 1.96, \quad \text{One-tail (right) } 1.645$$ $$\text{Critical } Z \text{ at } 1\%: \text{Two-tail } \pm 2.576, \quad \text{One-tail (right) } 2.33$$
Large Sample Z-Tests ($n \ge 30$)
$$\text{Single Mean: } Z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}}$$ $$\text{Diff Means: } Z = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}$$ $$\text{Single Proportion: } Z = \frac{p - P_0}{\sqrt{P_0 Q_0 / n}} \quad (p = x/n)$$ $$\text{Diff Proportions: } Z = \frac{p_1 - p_2}{\sqrt{\hat{P}\hat{Q}(1/n_1 + 1/n_2)}} \quad (\hat{P} = \frac{x_1+x_2}{n_1+n_2})$$
Small Sample t-Tests ($n < 30$)
$$\text{Single Mean: } t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}} \quad (\text{df } \nu = n-1), \quad s^2 = \frac{\sum(x-\bar{x})^2}{n-1}$$ $$\text{Diff Means: } t = \frac{\bar{x}_1 - \bar{x}_2}{s_p\sqrt{1/n_1 + 1/n_2}} \quad (\text{df } \nu = n_1+n_2-2)$$ $$s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}$$ $$\text{Paired t-Test: } t = \frac{\bar{d}}{s_d/\sqrt{n}} \quad (\text{df } \nu = n-1), \quad s_d^2 = \frac{\sum(d_i-\bar{d})^2}{n-1}$$
F-Test for Variances
$$F = \frac{s_1^2}{s_2^2} \quad (\text{ensure } s_1^2 > s_2^2 \implies F > 1)$$ $$\text{Numerator df } \nu_1 = n_1 - 1, \quad \text{Denominator df } \nu_2 = n_2 - 1$$
Chi-Square Tests ($\chi^2$)
$$\chi^2 = \sum \frac{(O - E)^2}{E} \quad (\text{df Goodness-of-Fit } \nu = k - 1 - p)$$ $$\text{df Independence: } \nu = (r - 1)(c - 1) \quad (\text{Expected cell } E_{ij} = \frac{R_i \cdot C_j}{N})$$ $$\text{Shortcut } 2\times 2: \chi^2 = \frac{N(ad - bc)^2}{(a+b)(c+d)(a+c)(b+d)}$$ $$\text{Yates Correction (cell < 5): } \chi^2_Y = \frac{N\left(|ad - bc| - \frac{N}{2}\right)^2}{(a+b)(c+d)(a+c)(b+d)}$$
Unit 5 Notes

Linear Programming Problems (LPP)

Covers formulation of Linear Programming problems, Graphical optimization, standard Simplex method, Big-M penalty methods, Two-Phase Simplex algorithm, and Primal-Dual relationships.

LPP_I.pdf
Open in New Tab

Syllabus Outline

LPP Formulation & Graphical
Formulation of mathematical models for linear optimization problems. Graphical solution of two-variable optimization.
Simplex Algorithms
Slack, surplus, and artificial variables. Standard Simplex method, Big-M method (penalty strategy), and Two-Phase Simplex method.
LPP Duality
Rules for converting a Primal LPP model to its Dual formulation, and economic interpretation of optimal dual variables.

Key Math Formulas

LPP Standard Form & Variables
$$\text{Max/Min } Z = \sum c_j x_j \quad \text{s.t. } Ax = b, \quad x_j \ge 0$$ $$\text{Slack (+s): Added to } \le \text{ constraints } (\text{Cost in } Z = 0)$$ $$\text{Surplus (-s): Subtracted from } \ge \text{ constraints } (\text{Cost in } Z = 0)$$ $$\text{Artificial (+a): Added to } \ge \text{ and } = \text{ constraints } (\text{Cost in } Z = \text{penalty})$$
Simplex Net Evaluations & Pivoting
$$\text{Net Eval: } \Delta_j = Z_j - C_j \quad (Z_j = \sum C_{bi} a_{ij})$$ $$\text{Entering Column: } \min(\Delta_j) \text{ s.t. } \Delta_j < 0 \quad (\text{Max } Z)$$ $$\text{Leaving Row: } \theta = \min_{i} \left\{ \frac{b_i}{a_{ij}} \mid a_{ij} > 0 \right\}$$ $$\text{New Pivot Row: } R_p = R_p / \text{Pivot Element}$$ $$\text{Other Rows: } R_i = R_i - (\text{entering col element}) \times R_p$$
Big-M Method Penalty Objective
$$\text{Maximize } Z = \sum c_j x_j - M\sum a_i \quad (M \to +\infty)$$ $$\text{Minimize } Z = \sum c_j x_j + M\sum a_i$$ $$\text{No Feasible Solution: Optimal checks met but artificial RV } a_i > 0 \text{ in basis}$$
Two-Phase Method Objectives
$$\text{Phase I: Drive artificials to } 0 \implies \text{Maximize } -Z^* = -\sum a_i$$ $$\text{Phase II: Drop } a_i \text{ cols, restore original costs } c_j \implies \text{Max } Z = \sum c_j x_j$$
Primal-to-Dual Conversion Matrix
$$\text{Primal: Max } Z = c^T x \quad \text{s.t. } Ax \le b, \, x \ge 0$$ $$\implies \text{Dual: Min } W = y^T b \quad \text{s.t. } y^T A \ge c^T, \, y \ge 0$$ $$\text{Primal } x_j \text{ unrestricted} \implies \text{Dual } j\text{-th constraint is equality } (=)$$ $$\text{Primal } i\text{-th constraint is equality } (=) \implies \text{Dual } y_i \text{ unrestricted}$$
