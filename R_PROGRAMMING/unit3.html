Topic 01
The aggregate() Function
1
Group-wise Data Splitting & Computation
What is aggregate()?

The aggregate() function in R is used to **split a data frame into subsets based on categorical grouping variables, apply a mathematical summary function on each subset, and combine the results back into a clean rectangular data frame**.

⚠️ HIGHEST SEE EXAM WEIGHTAGE
Expect questions asking you to write complete, running code to summarize columns grouped by multiple factors using aggregate().
Syntax & Parameters Mapping
Syntax FormatUsage Context
aggregate(formula, data, FUN)The standard, highly readable formula syntax: value ~ group_factor.
aggregate(x, by, FUN)The traditional vector-list format. by must be wrapped as a named list().

Parameters: formula denotes the mapping (e.g. Salary ~ Dept), data represents the active data frame, and FUN represents the target mathematical function (like mean, sum, sd, length).

Execution Pipeline: Split-Apply-Combine
Input Data Frame
➔
Split rows by Categorical Groups
➔
Apply FUN (e.g., mean) to Groups
➔
Combine back into Data Frame
Program 3.1

Single & Multi-Factor aggregate() Calculations

R
emp <- data.frame(
  name = c("Alice", "Bob", "Charlie", "David", "Eve"),
  dept = c("IT", "HR", "IT", "HR", "IT"),
  gender = c("F", "M", "M", "M", "F"),
  salary = c(50000, 45000, 55000, 48000, 60000)
)

# 1. Formula Syntax: Mean salary grouped by dept
res1 <- aggregate(salary ~ dept, data = emp, FUN = mean)
print(res1)

# 2. Multi-factor: Mean salary grouped by dept AND gender
res2 <- aggregate(salary ~ dept + gender, data = emp, FUN = sum)
print(res2)
dept salary 1 HR 46500 2 IT 55000 dept gender salary 1 HR M 93000 2 IT F 110000 3 IT M 55000
Topic 02
The tapply() Function
2
Applying Functions on Vectors Split by Factors
What is tapply()?

The tapply() (Tagged Apply) function is used to **apply a summary function over subsets of a vector, where the subsets are defined by one or more categorical factors**. Unlike aggregate() which accepts and returns whole data frames, tapply() operates directly on **vectors** and returns an array or named vector.

Syntax & Parameters Mapping
R
tapply(X, INDEX, FUN, ..., simplify = TRUE)
  • X: An atomic vector (usually numeric) containing the values to summarize.
  • INDEX: A factor or list of factors of the identical length as X used to group the elements.
  • FUN: The summary mathematical function to apply.
  • simplify: If TRUE (default), it returns a named vector or array. If FALSE, it returns a list.
Comparison: aggregate() vs. tapply()
Featureaggregate()tapply()
Primary Input Data Frame Atomic Vector + Group Factor Vector
Return Format Data Frame (rectangular layout) Named Vector, Array, or List
Formula Support Yes (e.g. y ~ x) No
Multi-column Operations Yes, can summarize multiple columns simultaneously No, only one target vector at a time

Topic 03
Data & Variable Structure Diagnostics
3
Understanding Data & Vector Layouts Natively
1. Describe Data Structure

Before modeling, we run built-in diagnostic functions to extract high-level metadata about loaded structures:

  • class(x) — Returns the structural object blueprint (e.g. "data.frame", "matrix").
  • typeof(x) — Returns the low-level, physical C-level memory storage type (e.g. "double", "integer", "list").
  • str(x) — Displays structural details, data layout, dimensions, column types, and a value preview.
  • summary(x) — Computes statistical summaries (Min, 1st Quartile, Median, Mean, 3rd Quartile, Max).
2. Describe Variable Structure

We check individual columns using built-in assertions:

  • Type checks: is.numeric(v), is.character(v), is.factor(v), is.logical(v).
  • Frequency counts for categories: table(v) counts the frequencies of unique categorical occurrences.

The Tabular Parsers: read.csv() vs. read.table()
5
Tabular Data Parsers and Parameter Maps
Comparison: read.csv() vs. read.table()

In exams, you are often asked to distinguish between the two primary tabular data parsers in R. Keep these differences in mind:

  • read.table(): The parent, general-purpose tabular parser. It expects columns to be separated by **whitespace** (spaces or tabs) by default, and assumes **no header row is present** (header = FALSE) unless stated otherwise.
  • read.csv(): A convenient wrapper function built on top of read.table(). It defaults to a **comma separator** (sep = ",") and assumes **the first row contains column headers** (header = TRUE).

Topic 06
Excel Spreadsheets, JSON & XML
6
Handling Diverse Enterprise Data Formats
1. Excel Sheet Parsing via readxl

Base R cannot read Excel binaries (.xlsx / .xls) directly. We use Hadley Wickham's `readxl` library to load sheets without needing Java dependencies:

R Excel Parser
library(readxl)
excel_sheets("store_sales.xlsx")                       # Lists all sheet names inside the spreadsheet
df_sheet <- read_excel("store_sales.xlsx", sheet = 1)  # Loads sheet 1 into a data frame
2. JSON Ingestion via jsonlite

Web APIs return data in JavaScript Object Notation (JSON). We use jsonlite to parse JSON arrays directly into clean R structures:

R JSON Parser
library(jsonlite)
json_data <- fromJSON("https://api.github.com/users/octocat/repos")  # Automatically parses to a data frame
compact_json <- toJSON(json_data, pretty = TRUE)                      # Converts data frame back to nested JSON
3. XML Hierarchy Extraction via XML package

To parse markup configurations or XML trees, we use the `XML` package to parse nodes into a clean tabular data frame:

R XML Parser
library(XML)
xml_doc <- xmlParse("config.xml")
df_xml <- xmlToDataFrame(xml_doc)  # Converts the child nodes into columns

Why use R GUIs?

While coding in RStudio is powerful, graphical interfaces (GUIs) make R accessible to non-programmers. These interfaces provide **point-and-click dialogs** to load, filter, and run regressions on datasets, while automatically printing the underlying R code.

Complete SQLite Database Read, Write, and Query Pipeline

R

library(RSQLite)

# 1. Establish an in-memory SQLite database connection (requires no server setup)
con <- dbConnect(RSQLite::SQLite(), dbname = ":memory:")

dbWriteTable(con, "cars_table", mtcars)

# 3. Query the database using standard SQL and close connection

print(res_sql)

Topic 09
Pentaho & JasperReports Integration
9
Enterprise Business Intelligence Tools
1. JasperReports Server Integration

**JasperReports** is a popular Java-based reporting engine used to generate pixel-perfect PDF reports and interactive dashboards. R integrates with JasperReports Server using the **`Rserve`** package. Rserve runs R as a TCP/IP server, allowing the Jasper Java application to send computational queries and retrieve statistical plots directly.

2. Pentaho BI Integration

**Pentaho** is an enterprise Business Intelligence suite popular for its ETL (Extract, Transform, Load) engine, Pentaho Data Integration (PDI, also known as Kettle). R scripts integrate directly into Pentaho ETL pipelines using the **WEKA plugin** or the **R Script Executor** component. This allows data engineers to clean, transform, and load database tables, route the data through an R script to generate predictions, and output the results directly into a visual dashboard.
