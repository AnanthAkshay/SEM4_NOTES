Topic 01
Introduction to R Programming
1
The R Language & Ecosystem
What is R?

R is an open-source programming language and a software environment specifically designed for statistical computing, data analytics, and graphic visualizations. Created by Ross Ihaka and Robert Gentleman at the University of Auckland, New Zealand in 1993, R is named after the first names of its authors and is an implementation of the S programming language (created by John Chambers at Bell Labs).

Why do we need R? (Analytical Advantages)

Traditional general-purpose languages like Java and C++ require verbose loops and custom libraries to process tables and perform data calculations. R natively treats data collections as vectors, allowing you to run complex statistical analysis and data operations in a single line without writing loops.

💡 Standard Data Analytics Powerhouse
R provides direct, native tools for handling missing data, applying linear models, clustering, and performing statistical tests. Coupled with graphical packages like ggplot2, it is universally acknowledged as a premier environment for exploratory data analysis (EDA).
Core Features of R
  • Interpreted Language: Code is evaluated line-by-line in the console, meaning there is no compilation step needed. This allows for extremely interactive scripting.
  • Case-Sensitive: Identifiers marks, Marks, and MARKS represent three completely separate objects.
  • Vectorized Operations: Functions automatically apply to every item in a vector without needing an explicit loop.
  • Massive Package Ecosystem: Over 18,000 community-contributed packages are hosted on CRAN for domains ranging from advanced biostatistics to business analytics.
"V-I-P-E-C" — Vectorized, Interpreted, Packages, Extensible, Case-sensitive.
🗣️ Viva Check: What is S and how does it relate to R?

A: S is a statistical programming language developed by John Chambers at Bell Laboratories. R is a modern, open-source, highly extended implementation of S. Most code written in S runs unmodified on R.

Topic 02
Downloading & Installing R
2
Ecosystem Setup via CRAN
What is CRAN?

CRAN (Comprehensive R Archive Network) is a global network of web servers that host identical, completely up-to-date versions of R binaries, source code, packages, and documentation. It is the official central repository for downloading everything in the R ecosystem.

Installation Workflow
  1. Visit the official R project website: r-project.org.
  2. Click the download R link under the Getting Started section to view the list of CRAN Mirrors.
  3. Choose a mirror server geographically close to your location to ensure fast download speeds.
  4. Select your operating system:
    • Windows: Click install R for the first time, then download the latest executable installer (e.g., R-4.x.x-win.exe).
    • macOS: Download the appropriate .pkg file matching your processor structure (Apple Silicon M1/M2/M3 or Intel).
    • Linux: Install R using your distribution's terminal package manager (e.g., sudo apt install r-base for Ubuntu).
  5. Run the downloaded installer and complete the setup wizard using default options. This installs the core R engine and the default **R Console / GUI**.
🗣️ Viva Check: What is the R Console?

A: The R Console is the basic command-line interface (CLI) where you can type R commands directly. It evaluates code using the Read-Eval-Print Loop (REPL) mechanism and displays text outputs immediately.

RStudio is the standard, globally preferred Integrated Development Environment (IDE) built specifically for R programming. It provides a visual, multi-paned environment that integrates your script editor, console, variable tracking, and graphic plots.

Topic 04
Handling Packages in R
4
Package Management & Commands
What is a Package vs. a Library?

A package is a structured collection of R functions, compiled code, datasets, and documentation that extends R's baseline features. A library is the physical folder on your disk where these packages are unzipped and stored.

⚠️ Core Exam Note
Expect questions testing package handling commands. Make sure you remember to write **package names in quotes** inside install.packages() but as **bare words (no quotes needed)** inside library().
Essential Package Commands
ActionCommand SyntaxDescription
Install from CRAN install.packages("pkg_name") Downloads and compiles package files locally. Run once.
Load Package library(pkg_name) Loads package features into current active session memory. Run every session.
Check Loaded Packages (.packages()) Lists the names of all packages currently active in memory.
Update Packages update.packages() Checks CRAN and updates outdated packages in your local folders.
Remove Package remove.packages("pkg_name") Deletes the package from your local library files.
🗣️ Viva Check: What is the difference between library() and require()?

A: library() will throw a fatal error and stop script execution if the package is missing. require() returns a logical value (TRUE if loaded, FALSE if missing) and throws a warning instead. Thus, require() is widely used inside conditional statements.

Example Code: Safe Package Handling
R
# Conditional package loading
if (require(ggplot2)) {
  print("ggplot2 successfully loaded!")
} else {
  print("ggplot2 missing. Installing now...")
  install.packages("ggplot2")
  library(ggplot2)
}

R Syntax Foundations
Assignment Operators

R supports both <- and = for variable assignment. However, the left arrow <- is the standard, preferred assignment operator. The equals sign = is generally reserved for declaring argument values inside function calls.

Arithmetic & Modulo Operators

%%Modulo (Remainder calculation)17 %% 52

Comments in R

R comments are declared using the hash # character. There are no block/multi-line comment constructs in R. Multi-line descriptions are composed of consecutive single commented lines:

R
# This is comment line 1
# This is comment line 2
marks <- 85  # Inline comment
Console Output: print() vs. cat()
  • print(): Displays single values or objects. Prints quotes around strings and line markers like [1].
  • cat(): Concatenates and prints multiple elements. Strips quotes and bracket numbers. Requires manual newline \n insertion.
R
name <- "MSRIT"
print(name)
cat("Welcome to", name, "\n")
[1] "MSRIT" Welcome to MSRIT
Topic 06
Working with Directories
6
File System Context in R
What is the Working Directory?

The **Working Directory** is the default folder context on your local storage drive where R will search for input files (like CSVs or text tables) to load, and where it will save all outputs (plots, output sheets).

Directory Commands
CommandPurposeDescription
getwd() Get Working Directory Returns the current absolute path context as a string.
setwd("path") Set Working Directory Sets a new directory target. File path must be quoted.
list.files() or dir() List Files Returns a character vector listing all filenames in the active folder.
🚨 CRITICAL WINDOWS PATH ERROR
Windows file systems copy folder paths with backslashes (e.g. C:\data). In R, backslashes act as string escape characters. You MUST convert them to forward slashes (C:/data) or double backslashes (C:\\data) inside the setwd() path argument, else execution will fail!
Topic 07
Data Types & Core Structures
7
R Data Representation
The 5 Primary Atomic Data Types

Every single variable or element in R is composed of one of these atomic data types:

Atomic TypeDescriptionExampleType Verification
Numeric Double precision floating-point decimals (Default numeric type). 10.5, 3.14 is.numeric(x)
Integer Whole numbers. Requires the L suffix. 10L, 5L is.integer(x)
Character Strings or text characters wrapped in quotes. "R Language", 'A' is.character(x)
Logical Boolean variables. Must be capitalized. TRUE, FALSE, T, F is.logical(x)
Complex Imaginary mathematical numbers. 3 + 2i is.complex(x)
The 6 Core Data Structures

Atomic types are organized into standard operational data structures based on dimensions and type homogeneity:

Dimension Homogeneous (Elements of same type) Heterogeneous (Elements of different types)
1D (Linear) Vector (Standard sequence; created using c()) List (Key-value bag of different types/structures)
2D (Grid) Matrix (Row-Column grid of same type) Data Frame (Table where column types can differ)
Multi-D Array (Multi-layered homogeneous grids) Not natively defined

• Factor: Special 1D structure for categorical variables with fixed **levels** (e.g. factor(c("Male", "Female"))).

Type Checking and Casting

Use the is.* family to verify types, and the as.* family to perform data casting (coercion):

R
age <- 21.8
is.numeric(age)    # TRUE
is.integer(age)    # FALSE

age_int <- as.integer(age)  # 21 (Decimal is truncated)
age_char <- as.character(age) # "21.8"

🗣️ Viva Check: What is the difference between str() and summary()?

A: str() shows the **technical structure** — listing column names, data classes, and lengths. summary() shows **statistical descriptions** — computing medians, means, and quartiles for numeric variables, and category counts for factors.

Program 1.2

Atomic Vectors & Implicit Coercion Rule Tracing

R
# 1. Numeric vector manipulation
num_vec <- c(5, 12.5, 20L)
print(num_vec)
cat("Class:", class(num_vec), "| Type:", typeof(num_vec), "\n")
cat("Second Element:", num_vec[2], "\n\n") # 1-based indexing

# 2. Coercion tracing: mixed atomic types
coerced_vec <- c(100L, "Data Analytics", TRUE)
print(coerced_vec)
cat("Class after coercion:", class(coerced_vec), "| Type:", typeof(coerced_vec), "\n")
[1] 5.0 12.5 20.0 Class: numeric | Type: double Second Element: 12.5 [1] "100" "Data Analytics" "TRUE" Class after coercion: character | Type: character

Vector Homogeneity Rule: In R, vectors are strictly homogeneous. When elements of different atomic types are initialized in c(), R automatically coerces (casts) them to the safest compatible type (in this case, strings/character), maintaining uniform structure.
