Q1: What is the difference between a data frame and a matrix?

A: A framework that breaks a plot down into modular components: data, aesthetics (aes), geometries (geom), statistics, coordinates, and themes. Hadley Wickham's ggplot2 is built on this.

A: Exploratory Data Analysis — analyzing data to summarize its main characteristics, find patterns, detect anomalies, and check mathematical assumptions before modeling.
Q6: What is the difference between normalization and standardization?
A: Normalization rescales a column to [0, 1] using min-max. Standardization transforms a variable to have a mean of 0 and a standard deviation of 1 using scale().
Q7: What is the use of set.seed() in R?
A: Makes random operations reproducible. Setting the seed ensures R's pseudo-random number generator outputs the exact same numbers every time the code runs.

Q15: What does str() show that summary() does not?
A: str() shows the technical layout — column names, types (character, numeric), and vector lengths. summary() shows statistical summaries like mean, median, and quartile boundaries.
