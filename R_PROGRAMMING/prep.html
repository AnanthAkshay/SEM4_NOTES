🗣️ Solved Viva Voce Questions (16 Questions) ▼
Q1: What is the difference between a data frame and a matrix?
A: Data frames allow different data types per column (heterogeneous); matrices require all elements to be the exact same type (homogeneous). Both are 2D structures.
Q2: What is the difference between aggregate() and tapply()?
A: aggregate() operates on data frames and returns data frames; tapply() operates on vectors and returns arrays or named vectors.
Q3: How do you handle missing values in R?
A: Use is.na() to detect them. We can remove them using na.omit() or complete.cases(), ignore them inside math calculations using na.rm = TRUE, or replace them with the column mean/median.
Q4: What is the Grammar of Graphics?
A: A framework that breaks a plot down into modular components: data, aesthetics (aes), geometries (geom), statistics, coordinates, and themes. Hadley Wickham's ggplot2 is built on this.
Q5: What is EDA?
A: Exploratory Data Analysis — analyzing data to summarize its main characteristics, find patterns, detect anomalies, and check mathematical assumptions before modeling.
Q6: What is the difference between normalization and standardization?
A: Normalization rescales a column to [0, 1] using min-max. Standardization transforms a variable to have a mean of 0 and a standard deviation of 1 using scale().
Q7: What is the use of set.seed() in R?
A: Makes random operations reproducible. Setting the seed ensures R's pseudo-random number generator outputs the exact same numbers every time the code runs.
Q8: Name 5 built-in datasets in R.
A: mtcars, iris, airquality, ChickWeight, ToothGrowth, USArrests.
Q9: What does the $ operator do in R?
A: Accesses a column of a data frame or an element of a list by name. e.g., df$Name.
Q10: What is the use of the cut() function?
A: Converts a continuous numeric variable into discrete categories/intervals (bins).
Q11: What are the types of joins supported in merge()?
A: Inner join (default), Left join (all.x = TRUE), Right join (all.y = TRUE), and Full outer join (all = TRUE).
Q12: What is an outlier and how do we detect it?
A: A data point significantly different from others. We detect it using boxplots or the IQR method (points lying below Q1 - 1.5×IQR or above Q3 + 1.5×IQR).
Q13: What is the difference between df["col"] and df$col?
A: df["col"] returns a single-column **data frame**. df$col (or df[["col"]]) returns a **vector**.
Q14: What is Rattle in R?
A: A tab-based graphical user interface (GUI) for data mining in R. It provides a point-and-click interface to explore, model, and evaluate data while generating the underlying R code.
Q15: What does str() show that summary() does not?
A: str() shows the technical layout — column names, types (character, numeric), and vector lengths. summary() shows statistical summaries like mean, median, and quartile boundaries.
Q16: What is the difference between NA and NULL in R?
A: NA is a placeholder representing a **missing value** (has a type, takes up space). NULL represents the **complete absence of a value** (empty object, has no type, takes zero space).
⚡ Last-Minute Revision Checklist ▼

🔥 UNIT 3 & 4 — Key Points

  • aggregate(y ~ x, data, FUN) — group-wise data summarization ➔ returns a data frame.
  • tapply(X, INDEX, FUN) — applies a function on a vector split by levels ➔ returns an array.
  • read.csv(): defaults to header=TRUE and sep=",". Wrapper around read.table().
  • read.table(): defaults to header=FALSE and sep="" (whitespace).
  • Missing Values: is.na(x) detects NAs/NaNs. Treat using na.omit() or na.rm = TRUE.
  • R has no built-in mode function! Write a custom function using unique() and tabulate().
  • Outlier Boundaries: Below Q1 - 1.5×IQR or above Q3 + 1.5×IQR.

🔥 UNIT 5 — Key Points

  • Native Visualizations: hist() for histograms, plot(x, y) for scatter plots, barplot() for bar charts, boxplot() for boxplots.
  • ggplot2 syntax: ggplot(data, aes(x, y, color)) + geom_*().
  • Min-Max Normalization: Binds values to a strict [0, 1] range.
  • Z-score Standardization: Rescales values to mean = 0, standard deviation = 1 using scale().
  • Discretization: Use cut() to bin continuous variables into ordered categorical factors.
  • Validation: Train-Test Split (e.g., 70% train, 30% test) using sample(). Always run set.seed() first to lock reproducibility.
