Data Frames in R Programming
1
The Essential Tabular Data Structure
What is a Data Frame?

A **Data Frame** is the most widely used data structure in R for statistical computing and analytical data processing. It is a 2-dimensional, rectangular table representing **a list of vectors of equal length**. Each column represents a variable, and each row represents an observation.

While matrices require all elements to be the exact same datatype, **data frames permit columns to have completely different datatypes** (e.g., column 1 is numeric age, column 2 is character name, column 3 is factor gender).

Structure Comparison: Data Frame vs. Matrix vs. List

Dimensions 2D (Rows × Columns) 2D (Rows × Columns) 1D Linear
Homogeneity Heterogeneous (columns can differ) Homogeneous (all elements same type) Heterogeneous (elements can differ)

Topic 04
Subsetting & Joins: Slicing Tables
4
Table Querying and Joining Mechanics
1. Slicing and Filtering Data Frames

R supports rich, native querying methods to slice rows and columns based on indexes or conditions:

  • Index-based slicing: df[1:5, c("Name", "CGPA")] extracts the first five rows for columns Name and CGPA.
  • Logical Filtering: df[df$CGPA > 8.5, ] filters rows matching the condition (always remember the trailing comma , to keep all columns!).
  • The subset() wrapper: subset(df, CGPA > 8.5 & Age >= 21) provides a clean syntax without needing dollar-signs.
2. Joining Data Frames via SQL Joins

To merge separate tables on matching key columns, R uses the merge() function:

R Join Configurations
merge(df1, df2, by = "ID")                    # Inner Join (keeps only matching rows)
merge(df1, df2, by = "ID", all.x = TRUE)      # Left Join (keeps all rows from left df1)
merge(df1, df2, by = "ID", all = TRUE)        # Full Outer Join (keeps all rows from both tables)

Topic 06
Missing, Invalid Values & Outliers
6
Data Inconsistencies & Anomaly Detection
1. Missing vs. Invalid Values
  • Missing Values (NA): Data points that are completely absent (handled via is.na(), na.omit(), or mean/median imputation).
  • Invalid Values: Data points that are present but **logically impossible** (e.g., age = -5, score = 150 when maximum is 100). Checked using logical filters and replaced with `NA` for cleaning.
2. Outlier Detection using the IQR Method

Outliers are extreme anomalies that skew statistical calculations (like means). We detect them mathematically using the **IQR (Inter-Quartile Range) Method**:

📐 Outlier Fences Formulas
* **IQR** = Q3 - Q1 (the distance between 75th and 25th percentiles). * **Lower Outlier Fence** = Q1 - 1.5 × IQR. * **Upper Outlier Fence** = Q3 + 1.5 × IQR. * **Anomalies:** Any value **less than the lower fence or greater than the upper fence** is flagged as an outlier!
Program 4.6

Outlier Detection using IQR

R
data <- c(12, 15, 14, 10, 13, 50, 11, 16, 14, 100)

Q1 <- quantile(data, 0.25)
Q3 <- quantile(data, 0.75)
IQR_val <- Q3 - Q1

lower_fence <- Q1 - 1.5 * IQR_val
upper_fence <- Q3 + 1.5 * IQR_val

outliers <- data[data < lower_fence | data > upper_fence]
cat("IQR:", IQR_val, "| Fence Range: [", lower_fence, ",", upper_fence, "]\n")
cat("Flagged Outliers:", outliers, "\n")
IQR: 4 | Fence Range: [ 5.75 , 21.75 ] Flagged Outliers: 50 100
Topic 07
Descriptive Statistics: Centrality & Dispersion
7
Mathematical Summaries of R Columns
1. Measures of Central Tendency
  • Mean: The mathematical average of a vector. Calculated using mean(x, na.rm = TRUE).
  • Median: The middle value when a vector is sorted. Calculated using median(x, na.rm = TRUE).
  • Mode: The value that appears most frequently in a dataset.
🚨 CRITICAL EXAM KNOWLEDGE: MODE IN R
**R has no built-in statistical mode function!** Running mode(x) does NOT calculate the statistical mode; instead, it returns the internal storage datatype of the vector (like `"numeric"` or `"character"`).
To find the statistical mode, you must write a **custom R function** that combines unique(), tabulate(), and which.max()!
2. Measures of Dispersion
  • Range: Min and Max values of a vector. Calculated using range(v).
  • Variance: Measures the spread of data points from the mean. Calculated using var(v). **R automatically uses the sample variance formula (dividing by $n-1$, not $n$)**.
  • Standard Deviation: Square root of variance. Calculated using sd(v).
  • Quantiles: Divides data points into percentiles. Calculated using quantile(v, probs = seq(0, 1, 0.25)).
Program 4.8

Central Tendency & Custom Mode Calculations

R
x <- c(10, 20, 20, 30, 40, 40, 40, 50)

# 1. Base R checks
cat("Mean:", mean(x), "| Median:", median(x), "\n")

# 2. Custom Mode Function (EXTREMELY IMPORTANT FOR EXAMS)
calc_mode <- function(v) {
  uniq <- unique(v)
  uniq[which.max(tabulate(match(v, uniq)))]
}
cat("Statistical Mode:", calc_mode(x), "\n")
cat("R mode(x) returns:", mode(x), "\n")

# 2. Exclude the 'Age' column (column index 3)
df_no_age <- df[, -3]
print(df_no_age)

# 3. Sort the rows of the data frame by Marks in descending order using order()
sorted_df <- df[order(-df$Marks), ]
