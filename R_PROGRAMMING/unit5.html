Topic 01
Histograms & Density Plots
1
Visualizing Single Continuous Variables
1. Histograms

A **histogram** is used to represent the frequency distribution of a **single continuous variable**. It groups the continuous value range into sequential, non-overlapping intervals (called **bins** or breaks) and renders a bar with height proportional to the number of data points falling in each bin.

Base R hist() Syntax
hist(x, breaks, col, main, xlab, ylab, freq = TRUE)

Parameters: breaks specifies the bin count, col fills the bars with color, and freq = FALSE converts the y-axis from absolute frequencies to probability densities (crucial for overlaying density curves!).

2. Density Estimation Plots

A **density plot** is a smoothed version of a histogram. It uses **Kernel Density Estimation (KDE)** to calculate and render the continuous probability density function of a variable. In Base R, we calculate this using density(v) and render it using the plot() canvas connector.

Program 5.1

Histogram with Overlaid Kernel Density Curve

R
marks <- c(45, 67, 78, 89, 92, 55, 71, 84, 63, 95, 50, 73, 88, 61, 76)

# 1. Render probability density histogram
hist(marks, freq = FALSE, col = "lightcoral", border = "white",
     main = "Marks Density with KDE", xlab = "Score")

# 2. Overlay KDE curve
lines(density(marks), col = "red", lwd = 2)
Topic 02
Scatter Plots & Line Plots
2
Visualizing Multi-Variable Relationships
1. Scatter Plots

A **scatter plot** maps the relationship between **two continuous variables** using cartesian dots. Each dot represents a single observation's coordinate. It is the primary tool to check for **correlations** (positive, negative, or none) between variables.

Common Parameters: pch sets the shape of the points (e.g. 19 for solid circles), and cex adjusts point size.

2. Line Plots

A **line plot** connects individual data points sequentially. It is widely used to visualize **trends over time** (time series data). In Base R, we render this by passing type = "l" inside the plot() function.

Program 5.2

Scatter Plot with Linear Regression Trendline

R
height <- c(150, 160, 165, 170, 175, 180, 155, 168)
weight <- c(50, 60, 65, 70, 75, 82, 55, 68)

# Render scatter points
plot(height, weight, main = "Height vs. Weight", 
     xlab = "Height (cm)", ylab = "Weight (kg)",
     col = "blue", pch = 19, cex = 1.5)

# Overlay fit line (lm performs linear model)
abline(lm(weight ~ height), col = "red", lwd = 2)
Topic 03
Bar Charts, Box Plots & Hexbin Plots
3
Categorical summaries and advanced grids
1. Bar Charts

A **bar chart** displays **categorical data** using rectangular bars. The height of each bar represents the category count or a summary value. We render this in Base R using `barplot()`.

2. Box Plots (Box-and-Whisker)

A **boxplot** is a compact visualization of a variable's **five-number summary**: Minimum, First Quartile (Q1), Median, Third Quartile (Q3), and Maximum. It visually flags outliers that lie beyond the fences.

  ┌─────┐
  │     │      • ← Outlier
──┤  Q3 ├──    ─ ← Upper Whisker (Q3 + 1.5*IQR)
  │─────│      ─ ← Median (Q2)
──┤  Q1 ├──    ─ ← Lower Whisker (Q1 - 1.5*IQR)
  │     │
  └─────┘
3. Hexbin Plots

Standard scatter plots become overcrowded when working with very large datasets. A **hexbin plot** solves this by dividing the 2D plane into regular hexagonal bins and using a color gradient to represent the density of points inside each hexagon.

Program 5.3

Boxplot Outliers Detection & Extraction

The advanced plots: ggplot2 Basics
4
Hadley Wickham's Grammar of Graphics
What is ggplot2?

The ggplot2 package is the standard tool for advanced data visualization in R. It is based on Leland Wilkinson's **Grammar of Graphics**, which views a plot not as a single image, but as a modular assembly of layered components:

Data (Data Frame)
+
Aesthetic Mapping (aes: x, y, color)
+
Geometric Layers (geom_*: points, bars)
The Core ggplot2 Layers Roadmap
Layer NamePurposeCommon Functions
Data & AestheticsSpecifies the dataset and maps columns to visual channels.ggplot(df, aes(x=wt, y=mpg))
Geometries (geom)Determines the visual shape used to render data points.geom_point(), geom_line(), geom_boxplot()
Statistics (stat)Applies computational transformations to the data.stat_summary(), stat_smooth()
Labels & ThemesSets titles, axes labels, and overall plot styling.labs(), theme_minimal(), theme_bw()

ggplot2 Multi-Layered Scatter & Boxplot Pipelines

  theme_minimal()

Data Transformations: Normalization & Standardization
6
Standardizing Variables Scales
Why transform data scales?

When dataset columns have completely different ranges (e.g. Salary in thousands, Age in double digits), algorithms may over-emphasize variables with larger absolute scales. We prevent this by transforming all variables to a **common scale** using two main methods:

Normalization vs. Standardization
TransformationMathematical FormulaResulting RangeBase R function
Min-Max Normalization$$x_{norm} = \frac{x - \min(x)}{\max(x) - \min(x)}$$Strictly bounded to [0, 1].Custom function
Z-Score Standardization$$x_{std} = \frac{x - \mu}{\sigma}$$Mean = 0, Standard Deviation = 1.scale(x)
Continuous to Discrete Conversion via cut()

To convert numerical columns into categorical ranges (e.g., converting scores 0-100 to Grade levels), R uses the cut() function:

R cut() syntax
grades <- cut(scores, breaks = c(0, 40, 75, 100), labels = c("Fail", "FirstClass", "Distinction"))

Data scaling & discretization pipeline

R
age <- c(20, 30, 40, 50, 60)

# 1. Custom Min-Max Normalization

Topic 07
Sampling & Validation: Train-Test Splits
7
Reproducible Random Splitting Pipelines
1. Random Sampling via sample()

R uses the `sample(x, size, replace)` function to select random subsets from a vector. Setting replace = TRUE enables sampling with replacement, which is the foundation of bootstrap aggregation.

2. Train-Test Splits (70-30 / 80-20)

In machine learning, we split our data to avoid **overfitting**: we build the model on the **training set** (e.g. 70% of rows) and evaluate its performance on an unseen **testing set** (the remaining 30% of rows).

🚨 EXAM TRAP: REPRODUCIBILITY IN SAMPLING
Because computers generate pseudo-random numbers, running a sampling function twice will yield different splits. You **MUST** run **`set.seed(n)`** immediately before sampling to lock R's random number generator. This ensures identical results every time the script is executed.
Program 5.6

Reproducible 70/30 Train-Test Split

R
set.seed(42)  # Locks random number generator

data(iris)
total_rows <- nrow(iris)
train_size <- round(0.7 * total_rows)

# Sample random row indexes
train_indexes <- sample(1:total_rows, size = train_size, replace = FALSE)

train_set <- iris[train_indexes, ]
test_set  <- iris[-train_indexes, ]

cat("Total dataset rows:", total_rows, "\n")
cat("Training set rows:", nrow(train_set), "\n")
cat("Testing set rows:", nrow(test_set), "\n")

Program 5.7

Complete Data Preprocessing and Transformation Pipeline

R
messy_df <- data.frame(
  Name = c("A", "B", "C", "D", "E", "A"),
  Age = c(21, NA, 22, -5, 23, 21),
  Score = c(85, 90, NA, 78, 200, 85),
  stringsAsFactors = FALSE
)

# 1. Impute missing values
messy_df$Age[is.na(messy_df$Age)] <- mean(messy_df$Age, na.rm = TRUE)
messy_df$Score[is.na(messy_df$Score)] <- median(messy_df$Score, na.rm = TRUE)

# 2. Treat invalid values
messy_df$Age[messy_df$Age < 0] <- median(messy_df$Age, na.rm = TRUE)
messy_df$Score[messy_df$Score > 100] <- 100

# 3. Filter out duplicate rows
clean_df <- messy_df[!duplicated(messy_df), ]
print(clean_df)
