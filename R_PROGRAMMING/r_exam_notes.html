Definition Introduction to R

▼

📖 What is R?

R is an open-source programming language and a software environment specifically designed for statistical computing, data analytics, and graphics. Created by Ross Ihaka and Robert Gentleman at the University of Auckland, New Zealand in 1993, R is named after the first names of its authors and is an implementation of the S programming language.

Q: Why is R preferred in data science over other general-purpose languages like C++ or Java?

A: R is vector-based (operations apply to whole vectors without explicit loops), has built-in statistical constructs, has the massive CRAN package repository containing thousands of specialized analytical packages, and offers state-of-the-art visualization libraries like ggplot2.

📌 Key Features of R

  • Interpreted Language — Code is executed line-by-line in the R console without needing compilation, facilitating iterative scripting.
  • Case-Sensitive — Variable names x and X are treated as completely distinct.
  • Vector-Based Architecture — Vectors are the fundamental atomic data structures. Math operations automatically propagate across all elements natively.
  • Extensible (CRAN Ecosystem) — Over 18,000 packages are hosted on CRAN (Comprehensive R Archive Network) for domains ranging from genomic sequencing to social media sentiment analysis.
"V-I-P-E-C" — Vectorized, Interpreted, Packages, Extensible, Case-sensitive.

Definition Downloading & Installing R

▼

📖 What is CRAN?

CRAN (Comprehensive R Archive Network) is a network of FTP and web servers around the world that store identical, up-to-date versions of code and documentation for R. It is the primary official repository for downloading R binaries and packages.

📌 Installation Workflow

  1. Go to the official R Project website: r-project.org.
  2. Click on the CRAN mirror link and choose a mirror server geographically close to you.
  3. Select your Operating System (Windows, macOS, or Linux).
    • For Windows: Click install R for the first time, then download the latest executable binary installer (e.g., R-4.x.x-win.exe).
    • For macOS: Download the appropriate .pkg file matching your processor (Apple Silicon M1/M2/M3 or Intel).
  4. Run the installer with default settings. Once complete, you can launch the **R GUI/Console** directly to run interactive code.

Q: What is the R Console?

A: The R Console is the standard command-line interface (CLI) where R code is entered, evaluated line-by-line (Read-Eval-Print Loop — REPL), and output is displayed immediately.

ImportantPYQ Handling Packages in R

▼

📖 What is a Package?

A package is a structured collection of R functions, compiled code, datasets, and documentation that extends R's core capabilities. Installed packages are stored in a local directory called a library.

Expect questions asking you to list and explain package handling functions with exact code examples. Make sure to differentiate between installing a package once and loading it every session.

📌 Core Package Commands

CommandSyntaxDescription
Installinstall.packages("package_name")Downloads and compiles the package from CRAN. Only needs to be run once.
Loadlibrary(package_name) or require(package_name)Loads package features into the current active session memory. Run every session.
Updateupdate.packages()Checks CRAN and updates all outdated packages installed in your library.
List Installedinstalled.packages()Lists details (version, paths) of all packages currently installed locally.
Removeremove.packages("package_name")Uninstalls the package and deletes its files from the local library directory.

Q: What is the difference between library() and require()?

A: library() will throw a fatal error and stop script execution if the package is missing. require() returns a logical value (TRUE if loaded, FALSE if missing) and throws a warning instead, making it ideal for conditional checks in scripts.

📌 Example Code: Handling a package

R
# Install ggplot2 from CRAN
install.packages("ggplot2")

# Load package safely
if (require(ggplot2)) {
  print("ggplot2 loaded successfully!")
} else {
  print("ggplot2 is missing. Installing now...")
  install.packages("ggplot2")
}

ImportantPYQ aggregate() Function

▼

📖 Definition

The aggregate() function in R is used to split the data into subsets, compute summary statistics for each subset, and return the result in a data frame. It is one of the most important functions for group-wise data processing.

This function is VERY frequently asked in exams — both as theory (explain aggregate) and as programs (write R code using aggregate).

📝 Syntax

SyntaxDescription
aggregate(formula, data, FUN)Formula-based: y ~ x means summarize y grouped by x
aggregate(x, by, FUN)x = data to summarize, by = list of grouping factors, FUN = function

📌 Key Parameters

  • formula — A formula like value ~ group; left side = variable to summarize, right side = grouping variable
  • data — The data frame to operate on
  • FUN — The function to apply (mean, sum, max, min, length, sd, etc.)
  • by — A list of grouping elements (used in non-formula syntax)
  • na.rm — Whether to remove NA values (TRUE/FALSE)

📌 How aggregate() Works — Step by Step

Input Data Frame → Split by Group → Apply FUN → Combine Results
Program 3.1

Basic aggregate() — Mean salary by department

R
# Create a data frame
emp <- data.frame(
  name = c("Alice", "Bob", "Charlie", "David", "Eve"),
  dept = c("IT", "HR", "IT", "HR", "IT"),
  salary = c(50000, 45000, 55000, 48000, 60000)
)

# Aggregate: mean salary by department
result <- aggregate(salary ~ dept, data = emp, FUN = mean)
print(result)
dept salary 1 HR 46500 2 IT 55000

Explanation: The formula salary ~ dept means "summarize salary grouped by dept". FUN = mean computes the average salary for each department. HR has (45000+48000)/2 = 46500, IT has (50000+55000+60000)/3 = 55000.

Q: What is the difference between formula syntax and list syntax in aggregate()?

A: Formula syntax: aggregate(y ~ x, data, FUN) — cleaner, uses data frame directly. List syntax: aggregate(x, by=list(), FUN) — more flexible, can use external vectors. Both give same results.

Common FUN values: mean, sum, max, min, length (count), sd (standard deviation), var (variance), median

ImportantViva tapply() Function

▼

📖 Definition

tapply() applies a function to subsets of a vector, split by the levels of a factor. It is used for group-wise operations on vectors. The name stands for "tagged apply" — it applies a function to groups identified by tags (factors).

📝 Syntax

R Syntax
tapply(X, INDEX, FUN, ..., simplify = TRUE)

# X       = numeric vector to apply function on
# INDEX   = factor/list of factors defining groups
# FUN     = function to apply (mean, sum, etc.)
# simplify = if TRUE, returns array; if FALSE, returns list

📌 Outliers

📖 What are Outliers?

Outliers are data points that differ significantly from other observations. They can be caused by measurement errors, data entry errors, or genuine extreme values. The IQR method is commonly used to detect outliers.

IQR Method Formula:

IQR = Q3 - Q1 (Inter-Quartile Range)
Lower Fence = Q1 - 1.5 × IQR
Upper Fence = Q3 + 1.5 × IQR
Any value below Lower Fence or above Upper Fence is an outlier.

Program 4.7

Detecting Outliers using IQR

R
data <- c(12,15,14,10,13,50,11,16,14,100)

Q3 <- quantile(data, 0.75)
IQR_val <- Q3 - Q1

lower <- Q1 - 1.5 * IQR_val
upper <- Q3 + 1.5 * IQR_val

outliers <- data[data < lower | data > upper]
cat("Q1:", Q1, "Q3:", Q3, "IQR:", IQR_val, "\n")
cat("Lower:", lower, "Upper:", upper, "\n")
cat("Outliers:", outliers, "\n")

📖 What is Normalization?

Normalization rescales data to a [0, 1] range. Formula: x_norm = (x - min) / (max - min). Used when features have different scales and you want them on a common scale.

DefinitionViva Sampling for Modeling & Validation

📖 What is Sampling?

Sampling is the process of selecting a subset of data from a larger dataset. In machine learning, data is split into training set (to build model) and test/validation set (to evaluate model). Common split: 70-30 or 80-20.

Program 5.10

# Set seed for reproducibility
set.seed(42)

# Train-Test Split (70-30)
data(iris)
n <- nrow(iris)

Training rows: 105 Testing rows: 45

set.seed(n): Sets the random number generator seed so that results are reproducible. Same seed → same random numbers every time. Essential for exams and reproducible research!

Q: Why do we split data into training and testing sets?

A: To avoid overfitting. The training set is used to build the model, and the test set is used to evaluate how well the model generalizes to unseen data. If we test on training data, the model may memorize the data instead of learning patterns.

Q1: What is the difference between a data frame and a matrix?

A: Data frames allow different data types per column; matrices require all elements to be the same type.

Q2: What is the difference between aggregate() and tapply()?

A: aggregate() works on data frames and returns data frames; tapply() works on vectors and returns arrays.

Q3: How do you handle missing values in R?

A: Use is.na() to detect, na.omit() to remove, replace with mean/median, or use na.rm=TRUE in functions.

Q4: What is the Grammar of Graphics?

A: A framework that breaks a plot into components: data, aesthetics (aes), geometries (geom), statistics, coordinates, and themes. ggplot2 is based on this.

Q5: What is EDA?

A: Exploratory Data Analysis — analyzing data to summarize characteristics, find patterns, detect anomalies, and check assumptions before modeling.

Q6: Difference between normalization and standardization?

A: Normalization scales to [0,1] using min-max. Standardization (z-score) transforms to mean=0, sd=1 using scale().

Q7: What is the use of set.seed() in R?

A: Makes random operations reproducible. Same seed always generates same random numbers.

Q8: Name 5 built-in datasets in R.

A: mtcars, iris, airquality, ChickWeight, ToothGrowth, USArrests, PlantGrowth

Q9: What does the $ operator do in R?

A: Accesses a column of a data frame or an element of a list by name. e.g., df$Name

Q10: What is the use of cut() function?

A: Converts a continuous numeric variable into discrete categories/intervals (bins).

Q11: What are the types of joins in merge()?

A: Inner join (default), Left join (all.x=TRUE), Right join (all.y=TRUE), Full outer join (all=TRUE).

Q12: What is an outlier and how to detect it?

A: A data point significantly different from others. Detect using boxplot or IQR method (below Q1-1.5*IQR or above Q3+1.5*IQR).

Q13: What is the difference between df["col"] and df$col?

A: df["col"] returns a data frame. df$col returns a vector.

Q14: What is Rattle in R?

A: A GUI-based tool for data mining in R. It provides point-and-click interface and generates R code automatically.

Q15: What does str() show that summary() does not?

A: str() shows data types and structure. summary() shows statistical measures (min, max, mean, quartiles).

Q16: What is the difference between NA and NULL in R?

A: NA = missing value (placeholder), NULL = absence of value (empty object). NA has a type, NULL has no type.
