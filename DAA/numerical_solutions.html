Matrix Chain Multiplication: A(10×8) × B(8×7) × C(7×2)
1. Problem Specification

Find the optimal multiplication sequence for three matrices A1(10 × 8), A2(8 × 7), and A3(7 × 2).

Dimensions: p0 = 10,  p1 = 8,  p2 = 7,  p3 = 2
Chain length: n = 3 (matrices indexed 1 to 3)
2. Recurrence Relation & Principles

The minimum cost m[i, j] to multiply matrices from index i to j is given by:

m[i, j] = mini ≤ k < j { m[i, k] + m[k+1, j] + pi-1pk pj }

For base cases where i = j, m[i, i] = 0.

3. Step-by-Step Dynamic Programming Calculations

Step 1: Base Cases (Chain Length l = 1)

m[1, 1] = 0,      m[2, 2] = 0,      m[3, 3] = 0

Step 2: Chain Length l = 2

  • Compute m[1, 2] (Multiplying A × B):
    m[1, 2] = m[1, 1] + m[2, 2] + p0 p1 p2 = 0 + 0 + 10 × 8 × 7 = 560
    Split point: s[1, 2] = 1
  • Compute m[2, 3] (Multiplying B × C):
    m[2, 3] = m[2, 2] + m[3, 3] + p1 p2 p3 = 0 + 0 + 8 × 7 × 2 = 112
    Split point: s[2, 3] = 2

Step 3: Chain Length l = 3

  • Compute m[1, 3] (Multiplying A × B × C):
    We evaluate the two possible split points k = 1 and k = 2:
    For k = 1 (Grouping A × (BC)):
    Cost1 = m[1, 1] + m[2, 3] + p0 p1 p3 = 0 + 112 + (10 × 8 × 2) = 112 + 160 = 272
    For k = 2 (Grouping (AB) × C):
    Cost2 = m[1, 2] + m[3, 3] + p0 p2 p3 = 560 + 0 + (10 × 7 × 2) = 560 + 140 = 700
    Taking the minimum: m[1, 3] = min(272, 700) = 272
    Optimal split point: s[1, 3] = 1

1. Problem Specification

p1 = 0.15,      p2 = 0.30,      p3 = 0.10,      p4 = 0.20

No dummy key probabilities are provided; we assume qi = 0 for i ∈ [0, 4].

For keys index i to j:

w(i, j) = ∑k=ij pk,      e[i, j] = mini ≤ r ≤ j { e[i, r-1] + e[r+1, j] + w(i, j) }

Base cases: e[i, i-1] = 0 and e[i, i] = pi.

Applying the Greedy Huffman tree builder by continuously merging two lowest frequency nodes:

  1. Merge 'H' (1) and 'm' (1) \implies T1 (2). Remaining list: T1(2), 'u'(2), 'f'(4), and remaining eight 1s.
  2. Merge 'a' (1) and 'n' (1) \implies T2 (2).

  4. Merge ' ' (1) and 'B' (1) \implies T4 (2).
  5. Merge 'e' (1) and 't' (1) \implies T5 (2).
  6. We now have nodes: 'f'(4), 'u'(2), T1(2), T2(2), T3(2), T4(2), T5(2).
  7. Merge 'u' (2) and T1 (2) \implies T6 (4).
  8. Merge T2 (2) and T3 (2) \implies T7 (4).
  9. Merge T4 (2) and T5 (2) \implies T8 (4).
  10. We now have: 'f'(4), T6(4), T7(4), T8(4).
  11. Merge 'f' (4) and T6 (4) \implies T9 (8).
  12. Merge T7 (4) and T8 (4) \implies T10 (8).
  13. Merge T9 (8) and T10 (8) \implies Root (16).
