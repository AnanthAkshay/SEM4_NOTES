🔁 MARKOV CHAIN – Two & Four Marks

1. Define stochastic process.
A stochastic process is a collection of random variables \(\{X_t, t \in T\}\) indexed by time \(t\), describing the evolution of a system over time.
2. Define Probability vector.
A row vector \( \mathbf{v} = [v_1, v_2, \dots, v_n] \) is a probability vector if \(v_i \ge 0\) for all \(i\) and \(\sum_{i=1}^n v_i = 1\).
3. Define stochastic matrix.
A square matrix \(P = [p_{ij}]\) is stochastic if each entry \(p_{ij} \ge 0\) and each row sums to 1: \(\sum_j p_{ij} = 1\) for all \(i\).
4. (i) Fixed vector (ii) Fixed probability vector of a stochastic matrix.
(i) A fixed vector of a matrix \(P\) is a row vector \(\pi\) such that \(\pi P = \pi\).
(ii) A fixed probability vector is a fixed vector that is also a probability vector (\(\sum \pi_i = 1, \pi_i \ge 0\)).
5. Define Markov process.
A stochastic process satisfying the Markov property: \(P(X_{n+1}=j \mid X_0,...,X_n) = P(X_{n+1}=j \mid X_n)\). Future depends only on present.
6. What is a Markov chain?
A Markov chain is a discrete‑time Markov process with a finite or countable state space. The transition probabilities are given by a stochastic matrix.
7. Define regular stochastic matrix.
A stochastic matrix \(P\) is regular if some power \(P^k\) has all positive entries (no zero entries).
8. Define Periodic state.
A state \(i\) has period \(d\) if \(d\) is the greatest common divisor of \(\{n \ge 1 : P^n_{ii} > 0\}\). If \(d>1\) the state is periodic.
9. Define Absorbing state.
State \(i\) is absorbing if \(p_{ii}=1\) (once entered, never leaves).
10. (i) Recurring state (ii) Transient state.
(i) Recurrent: starting from \(i\), the probability of ever returning to \(i\) is 1.
(ii) Transient: probability of eventual return is less than 1.

21. Consider repeated tosses of a fair die. Let \(X_n\) be the maximum of the numbers occurring in the first \(n\) trials.
(i) Find transition matrix of the Markov chain
(ii) Is this matrix regular?
(iii) Find the probability distribution after first toss
(iv) Find \(P^{(2)}\) and \(P^{(3)}\).
(i) Transition matrix: State space = {1,2,3,4,5,6}. From state \(i\) (current maximum = i), the next toss gives a number \(k\) with probability \(1/6\). If \(k \le i\), the maximum stays \(i\). If \(k > i\), the new maximum becomes \(k\). Thus: \[ p_{ij} = \begin{cases} \frac{i}{6} & \text{if } j = i \\ \frac{1}{6} & \text{if } j > i \\ 0 & \text{if } j < i \end{cases} \] So the transition matrix \(P\) is upper triangular: \[ P = \begin{bmatrix} \frac{1}{6} & \frac{1}{6} & \frac{1}{6} & \frac{1}{6} & \frac{1}{6} & \frac{1}{6} \\ 0 & \frac{2}{6} & \frac{1}{6} & \frac{1}{6} & \frac{1}{6} & \frac{1}{6} \\ 0 & 0 & \frac{3}{6} & \frac{1}{6} & \frac{1}{6} & \frac{1}{6} \\ 0 & 0 & 0 & \frac{4}{6} & \frac{1}{6} & \frac{1}{6} \\ 0 & 0 & 0 & 0 & \frac{5}{6} & \frac{1}{6} \\ 0 & 0 & 0 & 0 & 0 & 1 \end{bmatrix} \] (ii) Regular? A regular matrix must have all entries positive in some power. Here, because the matrix is upper triangular with zeros on the lower triangle, any power will also be upper triangular (zeros below diagonal). Therefore, it is not regular. (iii) Distribution after first toss: Starting from no toss (or after first toss), the maximum is simply the value of the first toss. 22. (M/M/1):(∞/FIFO) – Write expression for expected number of customers in the system \(L_s\).
\[ L_s = \frac{\rho}{1-\rho}, \quad \text{where } \rho = \frac{\lambda}{\mu} < 1 \] Derivation: \(L_s = \sum_{n=0}^\infty n P_n = \sum_{n=0}^\infty n (1-\rho)\rho^n = \frac{\rho}{1-\rho}\).
23. Expression for expected number of customers in the queue \(L_q\).
\[ L_q = \frac{\rho^2}{1-\rho} = \frac{\lambda^2}{\mu(\mu-\lambda)} \] This is the average number waiting (excluding the one in service).
24. Expression for expected number in nonempty queue \(L_w\).
\[ L_w = \frac{1}{1-\rho} \] This is the conditional expected queue length given that the queue is nonempty.
25. Expression for expected waiting time in system \(W_s\).
\[ W_s = \frac{1}{\mu - \lambda} = \frac{1}{\mu(1-\rho)} \]
26. Expression for expected waiting time in queue \(W_q\).
\[ W_q = \frac{\lambda}{\mu(\mu-\lambda)} = \frac{\rho}{\mu-\lambda} \]
27. Write Little’s Formulae for (M/M/1):(∞/FIFO).
\[ L_s = \lambda W_s, \qquad L_q = \lambda W_q \] These hold for any queuing system in steady state, not just M/M/1.
28. Probability that a customer has to wait more than 15 minutes to get service completed in (M/M/1):(∞/FIFO) if λ = 6 per hour and μ = 10 per hour.
\(\lambda = 6\), \(\mu = 10\) ⇒ \(\rho = 0.6\). For M/M/1, the system time \(W_s\) (total time in system) has CDF \(P(W_s \le t) = 1 - e^{-\mu(1-\rho)t}\). So \[ P(W_s > 0.25 \text{ hours}) = e^{-\mu(1-\rho)t} = e^{-10 \times 0.4 \times 0.25} = e^{-1} = 0.3679 \] 0.3679
