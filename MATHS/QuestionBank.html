✍️ Two & Four Marks Questions (Q1 – Q21)

1. Normal equations: y = a + bx (least squares)
Formula: For fitting \(y = a + bx\), minimize \(S = \sum (y_i - a - b x_i)^2\).
\(\frac{\partial S}{\partial a}=0\) and \(\frac{\partial S}{\partial b}=0\) give:
\[ \boxed{\sum y = n a + b \sum x},\qquad \boxed{\sum xy = a \sum x + b \sum x^2} \]
Final: Normal equations as above.
2. Normal equations: y = ax + b
Same form as Q1: \(\sum y = b\sum x + na\), \(\sum xy = b\sum x^2 + a\sum x\).
3. Normal equations: y = ax² + bx + c
\[ \begin{aligned} \sum y &= a\sum x^2 + b\sum x + nc\\ \sum xy &= a\sum x^3 + b\sum x^2 + c\sum x\\ \sum x^2y &= a\sum x^4 + b\sum x^3 + c\sum x^2 \end{aligned} \]
4. Normal equations: y = a + bx + cx²
\[ \sum y = na + b\sum x + c\sum x^2,\quad \sum xy = a\sum x + b\sum x^2 + c\sum x^3,\quad \sum x^2y = a\sum x^2 + b\sum x^3 + c\sum x^4 \]
5. Normal equations: y = ax² + bx (no constant)
\[ \sum y = a\sum x^2 + b\sum x,\qquad \sum xy = a\sum x^3 + b\sum x^2 \]
6. Procedure to fit y = a xᵇ (geometric curve)
Steps:
1. Linearize: \(\ln y = \ln a + b \ln x\)
2. Set \(Y = \ln y\), \(A = \ln a\), \(X = \ln x\) → \(Y = A + bX\)
3. Normal equations: \(\sum Y = nA + b\sum X\), \(\sum XY = A\sum X + b\sum X^2\)
4. Compute \(A\) and \(b\), then \(a = e^A\).
7. Procedure to fit y = a bˣ
\(\ln y = \ln a + x \ln b\). Set \(Y=\ln y\), \(A=\ln a\), \(B=\ln b\) → linear \(Y=A+Bx\).
Normal: \(\sum Y = nA + B\sum x\), \(\sum xY = A\sum x + B\sum x^2\). Then \(a=e^A\), \(b=e^B\).
8. Procedure to fit y = a eᵇˣ
\(\ln y = \ln a + bx\). Set \(Y=\ln y\), \(A=\ln a\) → \(Y=A+bx\). Normal: \(\sum Y = nA + b\sum x\), \(\sum xY = A\sum x + b\sum x^2\).
9. Derive normal equations for y = a + bx
\(S=\sum (y_i - a - b x_i)^2\).
\(\frac{\partial S}{\partial a} = -2\sum (y_i-a-bx_i)=0\) ⇒ \(\sum y = na + b\sum x\).
\(\frac{\partial S}{\partial b} = -2\sum x_i(y_i-a-bx_i)=0\) ⇒ \(\sum xy = a\sum x + b\sum x^2\).
10. Derive normal equations for y = a + bx + cx²
\(S=\sum (y_i - a - b x_i - c x_i^2)^2\). Partial derivatives give three equations:
\(\frac{\partial S}{\partial a}=0\) ⇒ \(\sum y = na + b\sum x + c\sum x^2\)
\(\frac{\partial S}{\partial b}=0\) ⇒ \(\sum xy = a\sum x + b\sum x^2 + c\sum x^3\)
\(\frac{\partial S}{\partial c}=0\) ⇒ \(\sum x^2y = a\sum x^2 + b\sum x^3 + c\sum x^4\).
11. Define correlation & regression
  • Correlation: Measure of linear relationship between two variables (\(-1 \le r \le 1\)).
  • Regression: Mathematical equation to predict one variable from another.
12. Two formulas for correlation coefficient r
\[ r = \frac{\sum (x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum (x_i-\bar x)^2\sum (y_i-\bar y)^2}} = \frac{n\sum xy - \sum x \sum y}{\sqrt{[n\sum x^2-(\sum x)^2][n\sum y^2-(\sum y)^2]}} \]
13. Regression line equations
\(y\) on \(x\): \(y-\bar y = r\frac{\sigma_y}{\sigma_x}(x-\bar x)\)
\(x\) on \(y\): \(x-\bar x = r\frac{\sigma_x}{\sigma_y}(y-\bar y)\)
14. Significance of r
\(|r|\) near 1 → strong linear correlation; \(r=0\) → no linear relation; sign indicates direction (positive/negative).
15. Show \(-1 \le r \le 1\)
By Cauchy-Schwarz inequality: \(|\sum (x_i-\bar x)(y_i-\bar y)| \le \sqrt{\sum (x_i-\bar x)^2 \sum (y_i-\bar y)^2}\). Dividing gives \(|r|\le 1\).
16. Prove r = GM of regression coefficients
\(b_{yx}=r\frac{\sigma_y}{\sigma_x}\), \(b_{xy}=r\frac{\sigma_x}{\sigma_y}\). Multiply: \(b_{yx}b_{xy}=r^2 \Rightarrow r = \pm\sqrt{b_{yx}b_{xy}}\).

20. Normal eqns: \(Y=\beta_0+\beta_1 X_1+\beta_2 X_2\)
\[ \begin{aligned} \sum Y &= n\beta_0 + \beta_1\sum X_1 + \beta_2\sum X_2\\ \sum X_1Y &= \beta_0\sum X_1 + \beta_1\sum X_1^2 + \beta_2\sum X_1X_2\\ \sum X_2Y &= \beta_0\sum X_2 + \beta_1\sum X_1X_2 + \beta_2\sum X_2^2 \end{aligned} \]

🎲 Random Variables & Expectation (Q41 – Q58)

41. Define random variable
A function that assigns a real number to each outcome of a random experiment. Example: number of heads in 2 tosses.
42. Discrete RV example
Takes countable values: e.g., X = {0,1,2,3} for number of heads in 3 coin tosses.
43. Continuous RV example
Takes any value in an interval: e.g., height, temperature, time.
44. Mathematical expectation
\(E[X] = \sum x_i P(X=x_i)\) (discrete) or \(\int x f(x)dx\) (continuous).
45. Variance
\(\text{Var}(X)=E[(X-\mu)^2]=E[X^2]-(E[X])^2\).
46. Prove \(\sigma^2 = E(X^2)-[E(X)]^2\)
\(\sigma^2 = E[(X-\mu)^2] = E[X^2-2\mu X+\mu^2] = E[X^2]-2\mu E[X]+\mu^2 = E[X^2]-\mu^2\).
