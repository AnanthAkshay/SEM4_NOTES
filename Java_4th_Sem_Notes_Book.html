Course Syllabus Blueprint

Unit 1: Java OOP Basics & Exceptions
Core definitions, constructors, overloading, static/final, method overriding, super, packages, interfaces, access protection, and detailed try-catch exception handling hierarchy.
Unit 2: String API, Lambdas & Multithreading
String memory pool optimization, StringBuffer mutability, type wrappers, functional interface lambdas, thread creation models, isAlive(), and join() thread coordination.
Unit 3: Java Collections Framework & Generics
Exhaustive Collections APIs (List, Set, Map, Queues), Iterator vs Iterable, Comparator, Comparable, and Type-Safe generic classes or methods.
Unit 4: Swing GUI & JDBC Database Connectivity
MVC structural pattern, lightweight Swing components, ActionListener events, JDBC architecture, SQL driver steps, Statement vs PreparedStatement, and ResultSets.
Unit 5: Java Servlets & JSP Technology
Lightweight servlet threads vs processes, lifecycle (init/service/destroy), ServletConfig vs Context, GET/POST forms, JSP lifecycle translation phases, scripting tags, and 9 implicit objects.
