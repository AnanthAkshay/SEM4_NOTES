Experiment 5

Aim

To design and implement the Library Book Lending System and perform SQL queries.

Problem Statement

Consider the Book Lending System consisting of BOOKS, STUDENT and BORROWS. Students can borrow any number of books. Book details include ISBN, Title, Author and Publisher.

Constraints

  • ISBN is Primary Key of BOOKS.
  • StudentID is Primary Key of STUDENT.
  • A student can borrow multiple books.
  • A book can be borrowed by multiple students.
  • ISBN in BORROWS references BOOKS(ISBN).
  • StudentID in BORROWS references STUDENT(StudentID).

Create Table Statements

CREATE TABLE Books(
ISBN VARCHAR2(10) PRIMARY KEY,
Title VARCHAR2(50),
Author VARCHAR2(30),
Publisher VARCHAR2(30)
);

CREATE TABLE Student(
StudentID NUMBER PRIMARY KEY,
StudentName VARCHAR2(30),
Gender VARCHAR2(10)
);

CREATE TABLE Borrows(
StudentID NUMBER,
ISBN VARCHAR2(10),
BorrowDate DATE,
PRIMARY KEY(StudentID,ISBN),
FOREIGN KEY(StudentID)
REFERENCES Student(StudentID),
FOREIGN KEY(ISBN)
REFERENCES Books(ISBN)
);

Query 1

Obtain names of students who borrowed ISBN 123 or ISBN 124.

SELECT DISTINCT S.StudentName
FROM Student S
JOIN Borrows B
ON S.StudentID=B.StudentID
WHERE B.ISBN IN ('123','124');

Query 2

Obtain names of female students who borrowed Database books.

SELECT S.StudentName
FROM Student S
JOIN Borrows B
ON S.StudentID=B.StudentID
JOIN Books BK
ON BK.ISBN=B.ISBN
WHERE S.Gender='Female'
AND BK.Title='Database';

Output

Student Name
Sneha

Query 3

Find number of books borrowed by each student.

SELECT S.StudentID,
S.StudentName,
COUNT(B.ISBN) AS BooksBorrowed
FROM Student S
LEFT JOIN Borrows B
ON S.StudentID=B.StudentID
GROUP BY S.StudentID,S.StudentName;
