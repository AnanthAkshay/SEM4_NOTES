Experiment 3

Aim

To design and implement BOAT, SAILOR and RESERVES relations and perform SQL queries.

Problem Statement

Consider the relations BOAT, SAILOR and RESERVES. Boats are identified by BID, color and name. Sailors are identified by SID, name and age. Sailors can reserve any number of boats and reservation details are stored in RESERVES.

Constraints

  • BID is Primary Key of BOAT.
  • SID is Primary Key of SAILOR.
  • (SID,BID,ReserveDate) uniquely identifies a reservation.
  • SID in RESERVES references SAILOR(SID).
  • BID in RESERVES references BOAT(BID).
  • A sailor can reserve many boats.
  • A boat can be reserved by many sailors.

Create Table Statements

CREATE TABLE Boat(
BID NUMBER PRIMARY KEY,
BName VARCHAR2(30),
Color VARCHAR2(20)
);

CREATE TABLE Sailor(
SID NUMBER PRIMARY KEY,
SailorName VARCHAR2(30),
Age NUMBER
);

CREATE TABLE Reserves(
SID NUMBER,
BID NUMBER,
ReserveDate DATE,
PRIMARY KEY(SID,BID,ReserveDate),
FOREIGN KEY(SID) REFERENCES Sailor(SID),
FOREIGN KEY(BID) REFERENCES Boat(BID)
);

Query 1

Obtain details of boats reserved by 'Rahul'

SELECT B.*
FROM Boat B
JOIN Reserves R ON B.BID=R.BID
JOIN Sailor S ON S.SID=R.SID
WHERE S.SailorName='Rahul';

Query 2

Retrieve BID of boats reserved by all sailors

SELECT BID
FROM Reserves
GROUP BY BID
HAVING COUNT(DISTINCT SID)=
(SELECT COUNT(*) FROM Sailor);

Output

BID
101

Query 3

Find number of boats reserved by each sailor

SELECT S.SailorName,
COUNT(R.BID) AS Boats_Reserved
FROM Sailor S
LEFT JOIN Reserves R
ON S.SID=R.SID
GROUP BY S.SailorName;
