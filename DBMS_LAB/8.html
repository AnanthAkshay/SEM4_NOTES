DATABASE MANAGEMENT SYSTEMS LAB

Experiment 8

Aim

To perform MongoDB operations on Patient and Doctor collections and update consultation fees.

Problem Statement

Create Patient and Doctor collections using MongoDB and perform the required queries. Also write a program that increases consultation fees of doctors in a given specialization by 20%.

Create Collections

db.Doctor.insertMany([
{
DoctorID:101,
DoctorName:"Dr. Kumar",
Specialization:"Cardiology",
Fee:500
},
{
DoctorID:102,
DoctorName:"Dr. Sharma",
Specialization:"Neurology",
Fee:700
}
]);

db.Patient.insertMany([
{
PatientID:1,
PatientName:"Rahul",
DoctorID:101,
AppointmentDate:"2025-01-10"
},
{
PatientID:2,
PatientName:"Sneha",
DoctorID:101,
AppointmentDate:"2025-01-10"
},
{
PatientID:3,
PatientName:"Ananth",
DoctorID:102,
AppointmentDate:"2025-01-12"
}
]);

Query 1

List all patients treated by doctor 'Dr. Kumar'

var doctor =
db.Doctor.findOne(
{DoctorName:"Dr. Kumar"}
);

db.Patient.find(
{DoctorID:doctor.DoctorID}
);

Query 2

Display names of patients who have appointment on '2025-01-10'

db.Patient.find(
{AppointmentDate:"2025-01-10"},
{_id:0,PatientName:1}
);

Program

Increase consultation fee of doctors in Cardiology by 20%

var result =
db.Doctor.updateMany(
{Specialization:"Cardiology"},
{
$mul:{Fee:1.20}
}
);

print(
result.modifiedCount +
" doctors were updated"
);

Expected Output

1 doctors were updated

Result

MongoDB collections were created successfully and the required operations were executed successfully.
