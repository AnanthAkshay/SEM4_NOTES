DATABASE MANAGEMENT SYSTEMS LAB

Experiment 4

Aim

To design and implement the Banking Database and perform SQL queries.

Problem Statement

Consider the Banking database consisting of CUSTOMER, BRANCH, ACCOUNT and TRANSACTION. A customer can have savings and current accounts. Transactions may be deposits or withdrawals.

Constraints

  • CustomerID is Primary Key of CUSTOMER.
  • BranchID is Primary Key of BRANCH.
  • AccountNo is Primary Key of ACCOUNT.
  • TransactionID is Primary Key of TRANSACTION.
  • Customer can have multiple accounts.
  • Branch can maintain multiple accounts.
  • Account belongs to one Customer and one Branch.
  • Transaction belongs to one Account.
  • AccountType can be Savings or Current.

Create Table Statements

CREATE TABLE Customer(
CustomerID NUMBER PRIMARY KEY,
CustomerName VARCHAR2(30),
City VARCHAR2(30)
);

CREATE TABLE Branch(
BranchID NUMBER PRIMARY KEY,
BranchName VARCHAR2(30),
Location VARCHAR2(30)
);

CREATE TABLE Account(
AccountNo NUMBER PRIMARY KEY,
AccountType VARCHAR2(20),
Balance NUMBER,
CustomerID NUMBER,
BranchID NUMBER,
FOREIGN KEY(CustomerID) REFERENCES Customer(CustomerID),
FOREIGN KEY(BranchID) REFERENCES Branch(BranchID)
);

CREATE TABLE Transaction_Details(
TransactionID NUMBER PRIMARY KEY,
TransType VARCHAR2(20),
Amount NUMBER,
AccountNo NUMBER,
FOREIGN KEY(AccountNo) REFERENCES Account(AccountNo)
);

Query 1

Obtain details of customers who have both Savings and Current Account.

SELECT C.*
FROM Customer C
WHERE C.CustomerID IN
(
SELECT CustomerID
FROM Account
GROUP BY CustomerID
HAVING COUNT(DISTINCT AccountType)=2
);

1RahulBangalore

Query 2

Retrieve branch details and number of accounts in each branch.

SELECT B.BranchID,B.BranchName,
COUNT(A.AccountNo) AS TotalAccounts
FROM Branch B
LEFT JOIN Account A
ON B.BranchID=A.BranchID
GROUP BY B.BranchID,B.BranchName;

Output

BranchIDBranchNameTotal Accounts
101SBI Main2
102SBI City1
103SBI North1

Query 3

Obtain customers who have performed at least 3 transactions.

SELECT DISTINCT C.*
FROM Customer C
JOIN Account A ON C.CustomerID=A.CustomerID
JOIN Transaction_Details T ON A.AccountNo=T.AccountNo
GROUP BY C.CustomerID,C.CustomerName,C.City
HAVING COUNT(T.TransactionID)>=3;

Output

CustomerIDCustomerNameCity
1RahulBangalore

Query 4

Branches having accounts less than average.

SELECT B.BranchID,B.BranchName
FROM Branch B
LEFT JOIN Account A
ON B.BranchID=A.BranchID
GROUP BY B.BranchID,B.BranchName
HAVING COUNT(A.AccountNo)
<
(
SELECT AVG(AccountCount)
FROM
(
SELECT COUNT(*) AccountCount
FROM Account
GROUP BY BranchID
)
);

BranchIDBranchName
102SBI City
103SBI North
