DATABASE MANAGEMENT SYSTEMS LAB

Experiment 10

Aim

To perform MongoDB operations on Boat and Sailor collections and implement a database trigger.

Problem Statement

Create collections and perform MongoDB operations. Write a trigger to prevent modifications to EMPLOYEE table on weekends.

Create Collections

db.Boat.insertMany([
{BID:101, BName:"Sea Queen", Color:"Red"},
{BID:102, BName:"Ocean Star", Color:"Blue"},
{BID:103, BName:"Wave Rider", Color:"Red"}
]);

db.Sailor.insertMany([
{SID:1, SailorName:"Rahul", Boats:[101,102]},
{SID:2, SailorName:"Ananth", Boats:[101]},
{SID:3, SailorName:"Sneha", Boats:[103]}
]);

Query 1

Obtain the number of boats reserved by sailor Rahul.

db.Sailor.aggregate([
{$match:{SailorName:"Rahul"}},
{
$project:{
SailorName:1,
BoatCount:{$size:"$Boats"}
}
}
]);

Query 2

Retrieve boats of color Red.

db.Boat.find(
{Color:"Red"}
);

Trigger Program

Raise an error if EMPLOYEE table is modified on Saturday or Sunday.

CREATE OR REPLACE TRIGGER trg_emp_weekend
BEFORE INSERT OR UPDATE OR DELETE
ON Employee
FOR EACH ROW
BEGIN

IF TO_CHAR(SYSDATE,'DAY')
IN ('SATURDAY','SUNDAY')
THEN

RAISE_APPLICATION_ERROR(
-20001,
'Modification Not Allowed On Weekend'
);

END IF;

END;
/

Expected Output

ORA-20001:
Modification Not Allowed On Weekend

Result

MongoDB operations and trigger execution were implemented successfully.
