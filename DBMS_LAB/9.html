DATABASE MANAGEMENT SYSTEMS LAB

Experiment 9

Aim

To perform MongoDB operations on Supplier, Part and Supply collections and implement a PL/SQL program.

Problem Statement

Create collections and perform MongoDB operations. Write a PL/SQL program to copy Shipment records to another table for a specified Part Number.

Create Collections

db.Part.insertMany([
{PID:101, PNAME:"Bolt", PCOLOR:"Red"},
{PID:102, PNAME:"Nut", PCOLOR:"Blue"}
]);

db.Supplier.insertMany([
{SID:1, SNAME:"ABC Suppliers"},
{SID:2, SNAME:"XYZ Traders"}
]);

db.Supply.insertMany([
{SID:1, PID:101, Quantity:500},
{SID:2, PID:101, Quantity:300},
{SID:2, PID:102, Quantity:200}
]);

Query 1

Update details of parts for a given PID.

db.Part.updateOne(
{PID:101},
{
$set:{
PNAME:"Steel Bolt",
PCOLOR:"Green"
}
}
);

Query 2

Display all suppliers who supply Part PID = 101.

db.Supplier.aggregate([
{
$lookup:{
from:"Supply",
localField:"SID",
foreignField:"SID",
as:"SupplyDetails"
}
},
{$unwind:"$SupplyDetails"},
{$match:{"SupplyDetails.PID":101}}
]);

PL/SQL Program

Copy Shipment records to another table for a specified PID.

CREATE TABLE Shipment_Backup AS
SELECT *
FROM Supply
WHERE 1=2;

DECLARE
v_pid NUMBER := 101;
BEGIN

INSERT INTO Shipment_Backup
SELECT *
FROM Supply
WHERE PID = v_pid;

COMMIT;

DBMS_OUTPUT.PUT_LINE(
'Records Copied Successfully'
);

END;
/

Expected Output

Records Copied Successfully

Result

MongoDB operations and PL/SQL program were executed successfully.
