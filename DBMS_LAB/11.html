Experiment 11

Aim

To perform MongoDB operations on Customer and Branch collections and demonstrate cursor usage in PL/SQL.

Problem Statement

Create Customer and Branch collections using MongoDB and perform the required operations. Use a cursor to copy contents from one table to another.

Create Collections

db.Branch.insertMany([
{BranchID:101, BranchName:"SBI Main"},
{BranchID:102, BranchName:"SBI City"}
]);

db.Customer.insertMany([
{
CustomerID:1,
CustomerName:"Rahul",
BranchID:101,
Accounts:[1001,1002]
},
{
CustomerID:2,
CustomerName:"Sneha",
BranchID:102,
Accounts:[1003]
}
]);

Query 1

Find Branch Name for a given Branch_ID.

db.Branch.find(
{BranchID:101},
{_id:0,BranchName:1}
);

Query 2

List total number of accounts for each customer.

db.Customer.aggregate([
{
$project:{
CustomerName:1,
TotalAccounts:{
$size:"$Accounts"
}
}
}
]);

PL/SQL Program Using Cursor

Copy contents of one table to another table.

CREATE TABLE Customer_Backup(
CustomerID NUMBER,
CustomerName VARCHAR2(30)
);

DECLARE

CURSOR c1 IS
SELECT CustomerID,
CustomerName
FROM Customer;

v_id Customer.CustomerID%TYPE;
v_name Customer.CustomerName%TYPE;

BEGIN

OPEN c1;

LOOP

FETCH c1
INTO v_id,v_name;

EXIT WHEN c1%NOTFOUND;

INSERT INTO Customer_Backup
VALUES(v_id,v_name);

END LOOP;

CLOSE c1;

COMMIT;

DBMS_OUTPUT.PUT_LINE(
'Records Copied Successfully'
);

END;
/

Expected Output

Records Copied Successfully

Result

MongoDB operations and cursor implementation were executed successfully.
