DATABASE MANAGEMENT SYSTEMS LAB

Experiment 1

Aim

To design an Employee–Department–Project database, create tables, insert data and perform SQL operations using Oracle SQL.

Problem Statement

Consider an Employee with a social security number (SSN) working on multiple projects with definite hours for each. Each Employee belongs to a Department. Each project is associated with some domain areas such as Database, Cloud and so on. Each Employee will be assigned to some project.

Constraints

  • SSN is Primary Key of Employee.
  • DeptNo is Primary Key of Department.
  • ProjectNo is Primary Key of Project.
  • Each Employee belongs to one Department.
  • Each Employee works on one or more Projects.
  • Hours worked must be greater than 0.
  • DeptNo and ProjectNo are Foreign Keys.

Create Table Statements

CREATE TABLE Department(
DeptNo NUMBER PRIMARY KEY,
DeptName VARCHAR2(30)
);

CREATE TABLE Project(
ProjectNo NUMBER PRIMARY KEY,
ProjectName VARCHAR2(30),
Domain VARCHAR2(30)
);

CREATE TABLE Employee(
SSN NUMBER PRIMARY KEY,
EmpName VARCHAR2(30),
Salary NUMBER,
DeptNo NUMBER,
ProjectNo NUMBER,
FOREIGN KEY(DeptNo)
REFERENCES Department(DeptNo),
FOREIGN KEY(ProjectNo)
REFERENCES Project(ProjectNo)
);

CREATE TABLE Works_On(
SSN NUMBER,
ProjectNo NUMBER,
Hours NUMBER,
PRIMARY KEY(SSN,ProjectNo),
FOREIGN KEY(SSN)
REFERENCES Employee(SSN),
FOREIGN KEY(ProjectNo)
REFERENCES Project(ProjectNo)
);

Query 1

Obtain details of employees assigned to Database project

SELECT E.*
FROM Employee E
JOIN Project P
ON E.ProjectNo=P.ProjectNo
WHERE P.Domain='Database';

Output

SSN EmpName Salary DeptNo ProjectNo
1001 Ananth 50000 10 101
1002 Rahul 55000 10 103
1004 Asha 65000 30 101

Query 2

Number of Employees in each Department

SELECT D.DeptNo,
D.DeptName,
COUNT(*) AS Employee_Count
FROM Employee E
JOIN Department D
ON E.DeptNo=D.DeptNo
GROUP BY D.DeptNo,D.DeptName;

Output

DeptNo DeptName Employee Count
10 CSE 2
20 ISE 1
30 ECE 1
