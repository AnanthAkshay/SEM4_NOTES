Experiment 6

Aim

To design and implement the Hospital Management System and perform SQL queries.

Problem Statement

Consider the Hospital Management System with PATIENT, DOCTOR and APPOINTMENT relations. Each patient can consult doctors on a specific date. Doctor details include specialization and consultation information.

Constraints

  • PatientID is Primary Key of PATIENT.
  • DoctorID is Primary Key of DOCTOR.
  • AppointmentID is Primary Key of APPOINTMENT.
  • A patient can consult multiple doctors.
  • A doctor can consult multiple patients.
  • PatientID in APPOINTMENT references PATIENT(PatientID).
  • DoctorID in APPOINTMENT references DOCTOR(DoctorID).

Create Table Statements

CREATE TABLE Patient(
PatientID NUMBER PRIMARY KEY,
PatientName VARCHAR2(30),
Age NUMBER,
Gender VARCHAR2(10)
);

CREATE TABLE Doctor(
DoctorID NUMBER PRIMARY KEY,
DoctorName VARCHAR2(30),
Specialization VARCHAR2(30)
);

CREATE TABLE Appointment(
AppointmentID NUMBER PRIMARY KEY,
PatientID NUMBER,
DoctorID NUMBER,
AppointmentDate DATE,
FOREIGN KEY(PatientID)
REFERENCES Patient(PatientID),
FOREIGN KEY(DoctorID)
REFERENCES Doctor(DoctorID)
);

Query 1

Retrieve details of doctors consulted by Rahul.

SELECT D.*
FROM Doctor D
JOIN Appointment A
ON D.DoctorID=A.DoctorID
JOIN Patient P
ON P.PatientID=A.PatientID
WHERE P.PatientName='Rahul';

Query 2

Find DoctorIDs of doctors consulted by all patients.

SELECT DoctorID
FROM Appointment
GROUP BY DoctorID
HAVING COUNT(DISTINCT PatientID)=
(SELECT COUNT(*) FROM Patient);

Output

DoctorID
101

Query 3

For each patient, find number of doctors consulted.

SELECT P.PatientName,
COUNT(A.DoctorID) AS DoctorsConsulted
FROM Patient P
LEFT JOIN Appointment A
ON P.PatientID=A.PatientID
GROUP BY P.PatientName;
