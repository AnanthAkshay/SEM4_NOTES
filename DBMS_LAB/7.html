DATABASE MANAGEMENT SYSTEMS LAB

Experiment 7

Aim

To perform MongoDB operations on Employee and Department collections and implement salary increment logic.

Problem Statement

Create Employee and Department collections using MongoDB and perform the required queries. Also write a program to give employees in a department a 15% pay increase.

MongoDB Collections

db.Department.insertMany([
{DeptNo:10, DeptName:"CSE"},
{DeptNo:20, DeptName:"ISE"}
]);

db.Employee.insertMany([
{EmpID:1, EmpName:"Rahul", Salary:50000, DeptNo:10, ProjectNo:101},
{EmpID:2, EmpName:"Ananth", Salary:60000, DeptNo:10, ProjectNo:102},
{EmpID:3, EmpName:"Sneha", Salary:55000, DeptNo:20, ProjectNo:101}
]);

Query 1

List all employees of Department named 'CSE'

db.Employee.aggregate([
{
$lookup:{
from:"Department",
localField:"DeptNo",
foreignField:"DeptNo",
as:"Dept"
}
},
{$unwind:"$Dept"},
{$match:{"Dept.DeptName":"CSE"}}
]);

Query 2

Name employees working on Project Number 101

db.Employee.find(
{ProjectNo:101},
{_id:0,EmpName:1}
);

Program

Give all employees in Department 10 a 15% pay increase

var result = db.Employee.updateMany(
{DeptNo:10},
[
{
$set:{
Salary:{
$multiply:["$Salary",1.15]
}
}
}
]
);

print(result.modifiedCount +
" employees were awarded the increase");

Expected Output

2 employees were awarded the increase

Result

MongoDB collections were created successfully and the required operations were executed successfully.
